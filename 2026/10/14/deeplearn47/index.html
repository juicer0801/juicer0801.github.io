以下是一篇尽可能覆盖回归与分类评估函数的笔记。组织逻辑是：先区分“损失函数”与“评估指标”，再按输出空间和任务结构分层展开。评估函数的选择本质上不是背公式，而是回答一个问题：你的预测要服务于什么决策，那个决策最怕什么错误？

回归与分类评估函数全景笔记

0. 先厘清两个概念：损失函数 vs 评估指标

二者经常被混用，但功能不同。

损失函数用于训练：需要可导、可优化，直接参与梯度更新。例如 MSE、交叉熵、Huber Loss。

评估指标用于判断和比较：不要求可导，但必须贴合业务目标和错误代价。例如 MAE、F1、AUC、mAP。

同一个函数可以两用：MSE 既是回归的经典损失，也是最常用的评估指标之一；交叉熵在分类中常作训练损失，评估时则常被 LogLoss 替代。但很多评估指标并不适合直接作损失（如 Accuracy、AUC、F1 不可导或分段常数），反过来有些损失也不适合直接作最终评估（如 Huber Loss 的绝对值大小依赖于 δ 的尺度）。

一个重要的选择原则是一致性：如果预测目标是条件均值，MSE/MAE 是严格一致的；如果预测目标是中位数，MAE/分位数损失是严格一致的；如果目标是概率，对数损失和 Brier Score 是严格proper scoring rule。评估函数与预测目标不对齐，优化得再好也可能在业务上无效。

1. 回归评估：输出是连续数值，核心是“误差多大、误差什么结构”

回归评估的第一分叉不是选哪个公式，而是你怕大误差，还是怕少数异常值，还是需要跨数据集比较。

1.1 绝对误差族：直观、稳健、保留原单位

MAE（Mean Absolute Error，平均绝对误差）

关心“平均而言，预测偏离真实值多少”，单位与目标变量一致，解释最直接。对异常值稳健，因为每个误差只按绝对值线性计入，不会被平方放大。适合误差分布厚尾、存在离群点、或业务上关心“典型偏差”的场景。盲点是对大误差不额外重罚，如果大误差的代价远高于小误差，MAE 会显得“宽容”。

MedAE（Median Absolute Error，中位绝对误差）

取绝对误差的中位数，比 MAE 更稳健：只要一半样本的绝对误差不大，少数极端偏差不会拉动指标。适合异常值比例不可忽略、且你只关心“大多数情况下准不准”的场景。代价是完全忽略尾部信息。

1.2 平方误差族：重罚大误差，是回归的默认基准

MSE（Mean Squared Error，均方误差）

对大误差施加平方级惩罚，因此对“偶尔错得很离谱”的模型非常不友好。MSE 的可导性使其成为训练中最常用的回归损失之一。但它的单位是目标变量的平方，单独看数值大小往往缺乏业务解释力；且对异常值高度敏感。

RMSE（Root Mean Squared Error，均方根误差）

MSE 的平方根，把单位还原到原尺度，解释力显著改善：“误差的典型量级大约是多少”。代价是仍然保留了对大误差的高敏感性，异常值会通过平方—开方过程被放大。当大误差的代价不成比例地高（如成本严重超支、价格剧烈波动下的预测）时，RMSE 是合理的首选。

1.3 相对误差族：跨尺度可比，但有零值陷阱

MAPE（Mean Absolute Percentage Error，平均绝对百分比误差）

把误差表达为真实值的百分比，天然适合不同量级的数据集之间比较，也便于向非技术方沟通“平均偏差百分之几”。核心缺陷是真实值接近或等于零时不稳定甚至无定义，且对低估和高估的惩罚不对称（分母是真实值，低估时百分比误差的上界受限于 100%，高估时没有上界）。在需求、价格、计数等可能取零的变量上应慎用。

SMAPE（Symmetric MAPE，对称平均绝对百分比误差）

用真实值与预测值的平均作分母，在一定程度上缓解了 MAPE 对低估/高估的不对称性，并且在 时仍有定义。但 SMAPE 仍然不是真正的“对称”，不同定义之间差异不小，且分母接近零时同样会放大误差。时间序列预测中常用，但需要明确使用的是哪一种 SMAPE 变体。

MASE（Mean Absolute Scaled Error，平均绝对标度误差）

分母是朴素季节性预测的平均绝对误差（用 个周期前的值作为预测）。这使 MASE 成为尺度无关的指标，且具有明确的基线含义：MASE < 1 表示模型优于季节性朴素预测，MASE > 1 表示还不如“抄去年同期”。特别适合时间序列中不同序列量级差异大、需要统一比较的场景，也避免了 MAPE 的零值问题。

1.4 拟合优度与相关性：解释了多少变异、趋势对不对

R²（Coefficient of Determination，决定系数）

衡量模型解释了多少目标变量的方差，取值理论上可负（模型比直接用均值预测还差），越接近 1 越好。R² 的优势是提供一个“相对于基线”的无量纲解释力度量，便于跨不同目标变量比较。但它不能单独说明预测误差有多大：R² 高不代表 MAE 小，R² 低也不一定意味着业务上不可用；且随样本量增加，R² 的估计会变化。

Adjusted R²（调整 R²）

对 R² 按特征数量做惩罚，防止“加特征就涨 R²”的虚假改善。在模型比较、尤其是特征数量不同的回归模型之间，比裸 R² 更可靠。

Pearson 相关系数

衡量预测值与真实值的线性相关强度，但不反映偏差方向和量级。两个模型可以有相同的 Pearson r，但一个系统性高估、一个系统性低估。适合作为趋势一致性的辅助指标，不宜单独作为回归评估的最终依据。

1.5 稳健回归与分位数回归的专用指标

Huber Loss

在小误差时表现为平方损失（保持效率），在大误差时退化为线性损失（限制异常值影响），是 MSE 和 MAE 之间的平滑折中。适合数据中混有少量离群点、但你又不想完全放弃平方损失效率的场景。评估时可以直接报告 Huber 值，但注意它依赖于 δ 的选取，跨数据集比较时需要固定 δ 或做标准化。

Quantile Loss / Pinball Loss（分位数损失）

用于预测特定分位数而非均值。 对应中位数（此时等价于 MAE）， 关注上分位数， 关注下分位数。适合非对称代价的场景：例如库存预测中缺货的代价远高于积压，或需要给出预测区间上下界时。评估分位数预测时，也应使用分位数损失而非 MSE/RMSE，否则评估目标与预测目标不一致。

1.6 区间预测与不确定性评估（进阶）

当模型不只输出点预测，而是输出预测区间 时，需要专门指标：

  • PICP（Prediction Interval Coverage Probability） ：观测值落入预测区间的比例，衡量覆盖率。理想情况下应接近名义置信水平（如 90% 区间应覆盖约 90% 的观测）。
  • PINAW / MPIW：区间宽度指标（归一化平均宽度 / 平均宽度）。覆盖率相同的情况下，区间越窄越好，因为更有信息量。
  • CWC（Coverage Width-based Criterion） ：综合覆盖率和宽度的准则，用于同时惩罚“覆盖不足”和“区间过宽”。

2. 分类评估：输出是离散类别或概率，核心是“什么错误更贵”

分类评估的第一分叉是你手里有什么输出：硬类别标签、概率/分数、还是排序结果。不同输出对应不同的指标族。

2.1 混淆矩阵：所有阈值分类指标的母体

二分类混淆矩阵：TP（真正例）、FP（假正例）、FN（假负例）、TN（真负例）。几乎所有阈值分类指标都可以从这四个量导出。

类别不平衡时，只看 Accuracy 会被多数类完全主导：99% 负类时，全部预测为负也能得到 99% 的 Accuracy，但正类召回率为 0。这也是后续一系列指标存在的理由。

2.2 阈值指标：判对没有、正类抓得怎样

Accuracy（准确率）

最直观，适合类别大致平衡、且各类错误代价相近的场景。类别不平衡时具有严重误导性。

Balanced Accuracy（平衡准确率）

各类召回率的宏平均（二分类时等于 Sensitivity 与 Specificity 的算术平均）。在不平衡数据上比裸 Accuracy 更诚实，因为它给少数类和多数类相同的权重。

Precision（精确率 / 查准率）

在“模型判为正类的样本”中，真正为正的比例。适合假正例代价高的场景：垃圾邮件过滤中误杀正常邮件、推荐系统中误推高风险内容。

Recall / Sensitivity（召回率 / 查全率 / 敏感度）

在“实际为正类的样本”中，被模型抓到的比例。适合假负例代价高的场景：疾病筛查、欺诈检测、故障预警——漏掉一个正例的代价远高于多报几个假警报。

F1 Score

精确率与召回率的调和平均，对两者不均衡施加惩罚。适合需要单一综合指标、且正类识别是核心任务的场景。但 F1 隐含地假设 Precision 和 Recall 同等重要；如果业务上漏报远比误报严重，应使用 （ 偏向 Recall）。

F-beta Score

时 Recall 权重更高， 时 Precision 权重更高。是 F1 的代价敏感推广。

Specificity（特异度）

负类中被正确识别的比例。在“误报代价高”或需要同时控制两类错误的场景中，常与 Sensitivity 成对报告。

Jaccard Index / IoU（交并比，分类形式）

与 F1 单调相关但数值不同，对重叠集合的“并”更敏感。在分割、检测等空间重叠评估中更自然。

Cohen’s Kappa

其中 是观测一致率（即 Accuracy）， 是随机一致率。Kappa 扣除“碰巧猜对”的部分，适合评估标注一致性或类别分布极偏时的分类表现。但 Kappa 对边际分布敏感，近年不少场景更推荐 MCC。

Matthews Correlation Coefficient（MCC）

本质上是真实标签与预测标签之间的 Pearson 相关系数，取值 ， 表示随机水平。MCC 在类别不平衡下比 F1 和 Kappa 更稳健，且同时利用了混淆矩阵的四个象限。当正负类都很重要、且不平衡严重时，MCC 是一个被低估的强指标。

2.3 概率质量与排序指标：模型“知不知道自己在说什么”

当模型输出概率或分数时，评估不再只关心“判对没有”，还关心概率是否可信、排序是否正确。

Log Loss / Cross-Entropy Loss（对数损失 / 交叉熵）

严格 proper scoring rule，同时惩罚“判错”和“过度自信”。一个模型把 0.99 的概率给错类别，LogLoss 会给出极大惩罚。适合需要校准概率质量的场景，也是分类训练的常用损失。盲点是对极端错误概率极度敏感，且不以 0/1 决策为直接目标。

Brier Score

二分类中即预测概率与真实 0/1 标签的均方误差；多分类时对各类概率求和。与 LogLoss 相比，Brier 对极端自信错误的惩罚更温和（平方而非对数），且解释更接近“概率预测的 MSE”。适合评估概率校准，尤其是气象、风险评分等概率本身有直接决策含义的领域。

ROC-AUC

ROC 曲线以 FPR 为横轴、TPR（Recall）为纵轴，AUC 是曲线下面积。AUC 有一个非常直观的概率解释：随机抽一个正例和一个负例，模型给正例打分高于负例的概率。它衡量的是排序能力，不依赖于某个特定阈值，因此适合“需要比较分数排序质量、或阈值尚未确定”的场景。但在极端不平衡且正类稀少时，AUC 可能给出乐观印象，因为 FPR 的分母（负类数量）很大，即使 FP 绝对数不少，FPR 仍可能很小。

PR-AUC（Precision-Recall AUC）

PR 曲线以 Recall 为横轴、Precision 为纵轴。PR-AUC 直接聚焦正类，在正类稀少、类别极度不平衡时比 ROC-AUC 更有区分力。代价是对正类的定义和阈值敏感，且不同实现（插值方式）之间可比性需要留意。

Average Precision（AP，分类/排序形式）

PR 曲线下的面积的一种离散计算方式，等价于 PR-AUC 的常见实现。在信息检索和多标签排序中是标准指标。

2.4 多分类的平均方式：macro / micro / weighted / samples

当分类从二分类扩展到多分类或多标签时，Precision、Recall、F1 等指标需要先“按类计算、再平均”。平均方式的选择会显著改变结论，不能默认用某一个。

Macro（宏平均） ：每类指标等权平均。适合每一类都重要、包括稀有类的场景；会突出模型在少数类上的表现，但也可能被个别极差的小类拉低整体分数。

Weighted（加权平均） ：按每类真实样本数加权。适合类别不平衡、且你关心“整体样本层面的表现”的场景；但它会低估少数类的重要性。

Micro（微平均） ：把所有类的 TP、FP、FN 加总后再计算指标。每个样本-类别对等权，大类的贡献自然更大。在多标签或“多数类应被关注”的多分类中常用。

Samples（样本平均，仅多标签） ：对每个样本单独计算指标再平均，不按类聚合。适合“每个样本的标签集合完整性都重要”的多标签场景。

一句话选择：稀有类重要 → macro；整体样本量导向 → weighted 或 micro；多标签逐样本评估 → samples。

3. 多标签分类的专门指标

多标签的输出是一个标签集合，而不是单个类别，因此除了对每个标签做二分类再平均，还有一组集合级指标。

Subset Accuracy（子集准确率 / Exact Match Ratio）

预测标签集合与真实集合完全一致才算正确。非常严格，适合标签数少、且“一个标签都不能错”的场景；标签数多时几乎所有模型都接近 0，区分力弱。

Hamming Loss

统计所有“样本-标签”对中被判错的比例，同时惩罚漏标和误标。越低越好，适合衡量整体标签预测的细粒度错误。

Ranking Loss

衡量“不相关标签被排在相关标签之前”的成对错误比例。只关心标签之间的相对顺序，不关心最终二值化阈值。适合标签排序质量重要的场景。

Coverage

平均需要沿排序列表“走多远”才能覆盖所有真实相关标签。越小越好，适合推荐式多标签输出、关心相关标签是否集中在排名前列的场景。

One-Error

排名最高的标签不是真实相关标签之一的样本比例。直接衡量“Top-1 预测错了多少次”，适合最相关标签必须排第一的临床诊断、主标签预测等场景。

Average Precision（多标签形式）

对每个样本，按排序计算 Precision@k 的加权平均，再对样本平均。同时考虑排序和集合覆盖，是多标签中常用的综合排序指标。

4. 目标检测的评估函数：从 IoU 到 mAP

目标检测的输出是“框 + 类别 + 置信度”，评估必须同时处理定位和分类。

IoU（Intersection over Union，交并比）

定位质量的基础度量。IoU ≥ 阈值（如 0.5）时，预测框才被视为该真实框的“命中”。

AP（Average Precision，单类平均精度）

综合了该类在不同召回水平下的精确率。

mAP（mean Average Precision）

对所有类别（或所有 IoU 阈值）的 AP 取平均。COCO 标准中 mAP 通常是在 IoU = 0.50:0.05:0.95 共 10 个阈值上取平均，同时报告 AP₅₀、AP₇₅ 以及按目标尺寸分层的 APₛ、APₘ、APₗ。mAP 是目标检测最核心的综合指标，但解释时需要明确 IoU 阈值集合和类别范围，否则不同论文/工具之间的数值不可直接比较。

5. 时间序列预测的补充指标

时间序列回归除了 MAE、MSE、RMSE 外，还有几个领域标准：

MASE：见 1.3，尺度无关且有“是否优于朴素预测”的基线含义，是 M4/M5 等预测竞赛的常用指标。

SMAPE：见 1.3，尺度无关，适合异质序列比较，但需注意变体定义和零值问题。

OWA（Overall Weighted Average） ：通常定义为 SMAPE 与 MASE 相对于朴素方法（Naive2）的归一化值的平均，用于综合排序。适合竞赛式统一比较，单独解释业务含义较弱。

6. 选择评估函数时的检查清单

与其记“哪个指标最好”，不如在每次评估前过一遍这五个问题：

① 输出是什么？ 连续值 → 回归指标；硬类别 → 阈值分类指标；概率/分数 → LogLoss、Brier、AUC/PR-AUC；集合 → 多标签指标；框 → IoU/AP/mAP。

② 错误代价对称吗？ 漏报和误报代价不同 → 不要用 Accuracy 或裸 F1，选 Recall/Precision 侧重、F-beta、分位数损失或代价敏感指标。

③ 类别/尺度平衡吗？ 分类不平衡 → Balanced Accuracy、MCC、PR-AUC、macro-F1；回归量级差异大 → MAPE/SMASE/MASE；但注意 MAPE 的零值陷阱。

④ 你怕大误差还是怕异常值？ 怕大误差 → MSE/RMSE；怕异常值 → MAE/MedAE/Huber；需要跨数据集比较 → 尺度无关指标。

⑤ 评估目标与预测目标对齐吗？ 预测均值却用分位数损失评估，或预测概率却只看 Accuracy，都会产生“指标好看但业务不好用”的错位。

最后一句总结：回归评估的核心分叉是误差的几何形状（是否平方、是否相对、是否分位数）；分类评估的核心分叉是决策阈值与错误代价（硬标签看 Precision/Recall/F1，概率看 LogLoss/Brier，排序看 AUC/PR-AUC）。多分类、多标签、检测和序列预测的指标，本质上都是这两条主线在更复杂输出结构上的展开。
