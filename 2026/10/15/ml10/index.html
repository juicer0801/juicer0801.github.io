1.2 决策树定义

决策树（Decision Tree） 是一种树形结构的分类/回归模型：

  • 内部节点：表示一个特征上的判断条件
  • 分支：表示判断结果的输出
  • 叶子节点：表示最终的分类结果或回归值

决策树的建立过程：

  1. 特征选择：选择分类能力强的特征
  2. 决策树生成：递归地构建决策树
  3. 剪枝：防止过拟合

1.3 决策树 vs 深度学习

对比项 决策树 深度学习
可解释性 ✅ 非常好（if-else规则） ❌ 黑盒模型
数据需求 少量数据即可 需要大量数据
特征工程 不需要标准化 通常需要标准化
训练速度 快 慢
适用场景 表格数据、规则明确 图像、文本、语音

从深度学习角度看决策树：

决策树就像是一个可解释的神经网络：

  • 每个节点 = 一个判断函数
  • 每个分支 = 一个条件分支
  • 整棵树 = 一个可解释的模型

2. 信息熵（Entropy）

2.1 什么是信息熵？

信息熵是信息论中度量不确定性的概念。

直观理解：

  • 熵越大 → 不确定性越高 → 越混乱
  • 熵越小 → 确定性越高 → 越有序

逐行解析：

  1. n = len(labels)：获取样本总数
  2. Counter(labels)：统计每个类别的样本数
  3. p = count / n：计算每个类别的概率
  4. ent -= p * np.log2(p)：累加每个类别对熵的贡献
  5. 返回最终的熵值

3.3 ID3算法流程

ID3算法步骤：

  1. 计算数据集D的经验熵H(D)
  2. 计算每个特征的信息增益
  3. 选择信息增益最大的特征
  4. 根据该特征的不同取值，将数据集划分为子集
  5. 对每个子集递归执行步骤1-4
  6. 直到满足停止条件（如：所有样本属于同一类、没有更多特征等）

4. C4.5决策树

4.1 ID3的缺点

ID3算法的问题：

ID3使用信息增益作为特征选择标准，但它有一个偏向性：

  • 倾向于选择取值较多的特征
  • 例如：如果用”身份证号”作为特征，每个样本的身份证号都不同，信息增益会很大，但这个特征没有泛化能力

5. CART决策树

5.1 CART简介

CART（Classification and Regression Trees） 是另一种经典的决策树算法。

CART的特点：

  1. 既可以分类，也可以回归
  2. 使用基尼指数（分类）或平方误差（回归）
  3. 一定是二叉树（每个节点只有两个分支）

6. 决策树剪枝

6.1 为什么需要剪枝？

过拟合问题：

决策树如果不加限制，会一直生长直到每个叶子节点只包含一个类别的样本。这会导致：

  • 训练集准确率很高
  • 测试集准确率很低（过拟合）

直观例子：

6.2 预剪枝（Pre-pruning）

预剪枝思想：

在决策树生成过程中，对每个节点在划分前先进行估计，若当前节点的划分不能带来泛化性能提升，则停止划分。

具体方法：

  1. 预留一部分数据作为验证集
  2. 每次划分前，用验证集评估划分效果
  3. 如果划分后验证集准确率下降，则停止划分

预剪枝优缺点：

优点 缺点
降低过拟合风险 可能欠拟合
减少训练时间 有些划分当前不好，但后续可能很好
减少测试时间 贪心策略，不是全局最优

6.3 后剪枝（Post-pruning）

后剪枝思想：

先构建完整的决策树，然后自底向上地对非叶节点进行考察，若将该节点对应的子树替换为叶节点能带来泛化性能提升，则进行剪枝。

具体方法：

  1. 构建完整的决策树
  2. 从叶子节点开始，自底向上考察每个非叶节点
  3. 用验证集评估：如果剪枝后准确率提升，则剪枝

后剪枝优缺点：

优点 缺点
欠拟合风险小 训练时间开销大
泛化性能通常更好 需要构建完整树
不是贪心策略 计算量大

8. 现代方法补充

8.1 随机森林（Random Forest）

随机森林思想：

构建多棵决策树，每棵树使用不同的数据子集和特征子集，最终通过投票或平均得到预测结果。

随机森林 vs 单棵决策树：

对比项 单棵决策树 随机森林
过拟合 容易过拟合 不容易过拟合
准确率 较低 较高
可解释性 好 较差
训练速度 快 较慢
稳定性 不稳定 稳定

8.2 XGBoost和LightGBM

XGBoost和LightGBM是基于决策树的梯度提升算法，在竞赛和工业界广泛应用。

8.3 决策树的应用场景

适合使用决策树的场景：

  1. 表格数据（结构化数据）
  2. 需要可解释性（医疗、金融等）
  3. 特征混合（数值特征和类别特征）
  4. 非线性关系

不适合使用决策树的场景：

  1. 图像、文本、语音（用深度学习）
  2. 特征维度很高（用线性模型或深度学习）
  3. 需要外推（决策树不能预测训练集范围外的值）

9. 小结

9.1 核心概念回顾

概念 说明
信息熵 度量数据的不确定性
信息增益 划分前后不确定性的减少量（ID3）
信息增益率 信息增益/固有值，对取值多的特征惩罚（C4.5）
基尼指数 随机抽取两个样本类别不一致的概率（CART）
剪枝 防止过拟合，分为预剪枝和后剪枝

9.2 三种决策树对比

算法 特征选择 分支方式 特点
ID3 信息增益 多叉树 偏向取值多的特征
C4.5 信息增益率 多叉树 修正了ID3的偏向
CART 基尼指数 二叉树 可分类可回归

9.3 决策树优缺点

优点：

  1. ✅ 可解释性强（if-else规则）
  2. ✅ 不需要特征标准化
  3. ✅ 可以处理数值和类别特征
  4. ✅ 训练速度快

缺点：

  1. ❌ 容易过拟合（需要剪枝）
  2. ❌ 不稳定（数据变化可能导致树结构大幅变化）
  3. ❌ 贪心算法（不能保证全局最优）
  4. ❌ 不能外推（不能预测训练集范围外的值）
