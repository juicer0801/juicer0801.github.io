1.2 线性回归的定义

线性回归（Linear Regression） 是一种监督学习算法，用于建立输入特征和连续目标值之间的线性关系。

核心思想：找到一条直线（或超平面），使得这条直线尽可能好地拟合所有数据点。

  • $x_1, x_2, …, x_n$：特征（输入）
  • $w_1, w_2, …, w_n$：权重（模型要学习的参数）
  • $b$：偏置（截距）

1.3 为什么要学线性回归？

你可能会问：我已经学了深度学习和RNN，为什么还要学这么简单的线性回归？

答案：

  1. 基础中的基础：线性回归是所有机器学习算法的起点
  2. 理解核心概念：损失函数、梯度下降、过拟合等概念都从这里开始
  3. 深度学习的基石：神经网络中的每一层本质上就是一个线性变换
  4. 实际应用广泛：房价预测、股票分析、销售预测等

2.2 如何衡量”好”？—— 损失函数

我们需要一个标准来衡量模型的好坏，这个标准就是损失函数（Loss Function）。

损失函数的作用：衡量预测值与真实值之间的差距。差距越小，模型越好。

均方误差（MSE）

最常用的损失函数是均方误差（Mean Squared Error, MSE）：

其中：

  • $n$：样本数量
  • $y_i$：第 $i$ 个样本的真实值
  • $\hat{y}_i = wx_i + b$：第 $i$ 个样本的预测值

直观理解：

  • 计算每个样本的误差：$(y_i - \hat{y}_i)$
  • 平方：避免正负误差抵消，同时放大较大误差
  • 求平均：得到整体误差

为什么要平方？

  1. 避免正负误差相互抵消
  2. 对大误差给予更大的惩罚
  3. 数学上便于求导

4. 梯度下降法

4.1 什么是梯度下降？

梯度下降（Gradient Descent） 是一种迭代优化算法，用于求解函数的最小值。

直观理解：想象你站在一座山上，想要下到山谷。你会怎么做？

  1. 环顾四周，找到最陡的下坡方向
  2. 沿着这个方向走一步
  3. 重复步骤1-2，直到到达山谷

对应到优化问题：

  • 山 = 损失函数的曲面
  • 山谷 = 损失函数的最小值
  • 你的位置 = 模型参数 $(w, b)$
  • 下坡方向 = 梯度的反方向

4.3 学习率的影响

学习率 $\alpha$ 是梯度下降中最重要的超参数之一：

学习率太小：

  • 收敛速度慢
  • 需要很多步才能到达最小值
  • 但最终能到达

学习率太大：

  • 可能跳过最小值
  • 在最小值附近震荡
  • 甚至发散（越来越差）

学习率刚好：

  • 收敛速度适中
  • 稳定到达最小值

4.6 梯度下降的变体

批量梯度下降（BGD）

使用所有样本计算梯度：

优点：稳定，收敛方向准确
缺点：当数据量大时，计算很慢

随机梯度下降（SGD）

每次只使用一个样本计算梯度：

优点：速度快，可以在线学习
缺点：波动大，收敛不稳定

小批量梯度下降（Mini-batch SGD）

每次使用一小批样本（通常32、64、128）：

优点：结合了BGD和SGD的优点
缺点：需要选择batch size

实际应用：深度学习中最常用的是Mini-batch SGD及其变体（Adam、RMSprop等）。

6. 特征标准化

6.1 为什么要标准化？

问题：不同特征的量纲和取值范围可能差异很大。

示例：预测房价

  • 面积：50-200 平方米
  • 房间数：1-5 间
  • 房龄：0-50 年

如果不做标准化：

  1. 面积的特征值远大于房间数
  2. 损失函数的等高线是椭圆形
  3. 梯度下降需要很多步才能收敛

标准化后：

  1. 所有特征都在相似的尺度上
  2. 损失函数的等高线接近圆形
  3. 梯度下降可以快速收敛

7. 回归评估指标

7.1 为什么需要评估指标？

训练完模型后，我们需要知道模型的性能如何。评估指标帮助我们：

  1. 衡量模型的预测精度
  2. 比较不同模型的性能
  3. 选择最优的超参数

7.2 常用评估指标

均方误差（MSE）

特点：

  • 对大误差敏感（因为平方）
  • 单位是目标值的平方
  • 最常用的评估指标

均方根误差（RMSE）

特点：

  • 单位与目标值相同
  • 更容易解释
  • 同样对大误差敏感

平均绝对误差（MAE）

特点：

  • 对异常值不敏感
  • 单位与目标值相同
  • 更鲁棒

R² 分数（决定系数）

特点：

  • 取值范围：(-∞, 1]
  • R² = 1：完美预测
  • R² = 0：等同于预测均值
  • R² < 0：比预测均值还差
  • 无量纲，便于比较

8. 正则化

8.1 什么是过拟合？

过拟合（Overfitting）：模型在训练集上表现很好，但在测试集上表现很差。

直观理解：模型”记住”了训练数据，而不是”学习”到了规律。

示例：

  • 训练集MSE：0.01
  • 测试集MSE：5.0

原因：

  1. 模型过于复杂
  2. 特征过多
  3. 训练数据不足
  4. 噪声干扰

8.2 什么是正则化？

正则化（Regularization）：在损失函数中添加惩罚项，限制模型复杂度，防止过拟合。

核心思想：

  • 鼓励模型学习简单的模式
  • 惩罚过大的权重
  • 提高模型的泛化能力

11. 本章小结

11.1 核心概念

概念 说明
线性回归 用线性模型拟合数据，预测连续值
损失函数 衡量模型预测与真实值的差距
正规方程 直接求解最优参数的解析方法
梯度下降 迭代优化求解最优参数的数值方法
学习率 控制梯度下降每步的大小
正则化 防止过拟合，限制模型复杂度
L1正则化 产生稀疏解，可做特征选择
L2正则化 减小权重，防止过拟合

11.2 算法对比

方法 优点 缺点 适用场景
正规方程 无需迭代，直接求解 计算复杂度高O(n³) 特征数量较少
梯度下降 适用于大规模数据 需要选择学习率 特征数量较多
Lasso 特征选择 计算复杂 特征很多，需要选择
Ridge 计算简单，稳定 不能特征选择 防止过拟合

附录：常见公式速查

损失函数

名称 公式 说明
MSE $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ 均方误差
MAE $\frac{1}{n}\sum\ y_i - \hat{y}_i\ $ 平均绝对误差
RMSE $\sqrt{MSE}$ 均方根误差

正则化

名称 公式 特点
L1 $\lambda\sum\ w_j\ $ 稀疏解，特征选择
L2 $\lambda\sum w_j^2$ 减小权重，防止过拟合

梯度

函数 梯度
$L = \frac{1}{n}\sum(y_i - \hat{y}_i)^2$ $\frac{\partial L}{\partial w} = \frac{2}{n}X^T(\hat{y} - y)$
L1正则项 $\lambda \cdot \text{sign}(w)$
L2正则项 $2\lambda w$
