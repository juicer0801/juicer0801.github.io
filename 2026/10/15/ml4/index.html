1. KNN算法思想

1.1 什么是KNN？

K-近邻算法（K Nearest Neighbor，简称KNN） 是一种基于实例的学习方法。

核心思想： 如果一个样本在特征空间中的 k 个最相似的样本中的大多数属于某一个类别，则该样本也属于这个类别。

通俗理解：

想象你搬到了一个新小区，你不知道自己属于哪个”圈子”。于是你观察了离你家最近的5户邻居，发现其中4户都是”程序员圈”，1户是”设计师圈”。那么根据KNN的思想，你就属于”程序员圈”。

1.2 一个直观的例子：电影分类

假设我们有以下电影数据，特征是”打斗镜头数”和”接吻镜头数”：

电影 打斗镜头数 接吻镜头数 类型
电影A 3 104 爱情片
电影B 2 100 爱情片
电影C 1 81 爱情片
电影D 101 10 动作片
电影E 99 5 动作片
电影F 98 2 动作片
未知电影 18 90 ?

现在有一部未知电影，打斗镜头18次，接吻镜头90次，请问它是什么类型？

KNN的判断过程：

  1. 计算距离：计算未知电影与所有已知电影的距离
  2. 排序：按距离从小到大排序
  3. 取K个最近邻：假设K=3，取最近的3部电影
  4. 投票：看这3部电影属于哪个类别最多

  2. 电影C：19.2（爱情片）
  3. 电影A：20.5（爱情片）
  4. 电影D：115.3（动作片）
  5. 电影E：117.4（动作片）

  • 电影A：爱情片

1.3 KNN的两种应用方式

分类问题

  • 流程： 计算距离 → 排序 → 取K个最近邻 → 多数表决
  • 输出： 类别标签

回归问题

  • 流程： 计算距离 → 排序 → 取K个最近邻 → 计算平均值
  • 输出： 连续值

例子： 假设K=3的最近邻的房价分别是 100万、120万、110万

  • 分类：看哪个类别最多
  • 回归：预测房价 = (100 + 120 + 110) / 3 = 110万

2.5 距离度量方法对比

距离类型 公式 特点 适用场景
欧氏距离 √(Σ(xi-yi)²) 直线距离，最常用 连续特征，各维度尺度相近
曼哈顿距离 Σ\ xi-yi\ 城市街区距离 高维数据，对异常值更鲁棒
切比雪夫距离 max(\ xi-yi\ ) 取最大差异 只关心最大差异的场景
闵可夫斯基距离 (Σ\ xi-yi\ ^p)^(1/p) 通用公式 p=1曼哈顿，p=2欧氏

选择建议：

  • 默认使用欧氏距离，大多数情况下效果不错
  • 高维数据考虑曼哈顿距离
  • 特征尺度差异大时，先做标准化再计算距离

3. K值选择

3.1 K值的影响

K值太小（如K=1）：

  • 模型复杂，容易过拟合
  • 对噪声敏感
  • 决策边界曲折

K值太大（如K=N，N为样本数）：

  • 模型简单，容易欠拟合
  • 预测结果趋向于多数类
  • 决策边界平滑

经验法则：

  • K值通常取奇数，避免投票时出现平局
  • 常用K值：3, 5, 7, 9
  • 通过交叉验证选择最优K值

3.2 可视化理解K值的影响

假设有以下二分类数据：

  • 红色圆点：类别0
  • 蓝色三角：类别1

● 是待预测点

  • K=1：最近的邻居是△，预测为类别1
  • K=3：最近的3个邻居是2个○和1个△，预测为类别0
  • K=5：最近的5个邻居是3个○和2个△，预测为类别0

4. 特征预处理

4.1 为什么要做特征预处理？

问题： 当特征的单位或数值范围差异很大时，会”支配”距离计算。

例子： 假设我们要预测房价，有两个特征：

  • 房屋面积：50-200 平方米
  • 房间数：1-5 间

如果不做预处理：

问题： 距离主要由面积决定（50² = 2500），房间数的影响微乎其微（1² = 1）！

解决： 对特征进行标准化或归一化，让每个特征都在相似的尺度上。

4.4 归一化 vs 标准化

方法 公式 值域 优点 缺点 适用场景
归一化 (x-min)/(max-min) [0, 1] 简单直观 受异常值影响大 小数据，精确场景
标准化 (x-μ)/σ (-∞, +∞) 对异常值鲁棒 值域无限制 大数据，KNN等距离算法

选择建议：

  • KNN、SVM、神经网络等基于距离的算法：必须做标准化
  • 决策树、随机森林等基于树的算法：不需要标准化
  • 不确定时：默认使用标准化

8. 交叉验证和网格搜索

8.1 交叉验证（Cross-Validation）

问题： 如何选择合适的K值？

简单方法： 将数据划分为训练集和验证集，在验证集上评估不同K值的效果。

问题： 这种划分方式依赖于特定的数据划分，结果不稳定。

解决方案：交叉验证

K折交叉验证（K-Fold Cross-Validation）：

  1. 将训练集划分为K份（如K=5）
  2. 第1次：第1份做验证集，其余4份做训练集
  3. 第2次：第2份做验证集，其余4份做训练集
  4. …
  5. 第K次：第K份做验证集，其余K-1份做训练集
  6. 取K次评估的平均值作为模型得分

9. KNN的优缺点

9.1 优点

  1. 简单易懂

    • 算法思想直观，容易理解
    • 实现简单，不需要训练

  2. 无需训练

    • 惰性学习，训练阶段很快
    • 可以随时添加新数据

  3. 适合多分类

    • 天然支持多分类问题
    • 不需要像SVM那样做特殊处理

  4. 非线性决策边界

    • 可以处理非线性可分的数据
    • 决策边界灵活

9.2 缺点

  1. 预测慢

    • 每次预测都要计算与所有训练样本的距离
    • 训练集大时很慢

  2. 内存消耗大

    • 需要保存所有训练数据
    • 不适合大数据集

  3. 对特征尺度敏感

    • 必须做特征标准化
    • 否则数值大的特征会主导距离计算

  4. 对高维数据效果差

    • 维度灾难（Curse of Dimensionality）
    • 高维空间中距离失去意义

  5. K值选择困难

    • K值对结果影响大
    • 需要通过交叉验证选择

9.3 适用场景

适合：

  • 小数据集
  • 低维特征
  • 多分类问题
  • 需要快速训练的场景

不适合：

  • 大数据集
  • 高维特征（如文本、图像）
  • 需要快速预测的场景
  • 特征尺度差异大的场景（除非做标准化）

10. KNN vs 深度学习

作为已经学过深度学习RNN的你，可能会问：KNN和深度学习有什么区别？

特性 KNN 深度学习（如RNN）
学习方式 惰性学习，不训练 主动学习，需要训练
模型复杂度 简单，无参数 复杂，数百万参数
训练时间 几乎为0 几小时到几天
预测时间 慢（计算所有距离） 快（前向传播）
内存消耗 大（保存所有数据） 小（只保存参数）
特征工程 必须做 可以自动学习特征
数据量 小数据 大数据
可解释性 高（可以看邻居） 低（黑盒）
适用场景 小数据、低维 大数据、高维

什么时候用KNN？

  • 数据量小（< 10万样本）
  • 特征维度低（< 100维）
  • 需要快速原型验证
  • 需要可解释性

什么时候用深度学习？

  • 数据量大（> 10万样本）
  • 特征维度高（如文本、图像）
  • 需要自动学习特征
  • 追求最高性能

11. 小结

11.1 核心概念

  1. KNN算法思想

    • 根据K个最近邻的多数表决进行分类
    • 根据K个最近邻的平均值进行回归

  2. 距离度量

    • 欧氏距离：直线距离，最常用
    • 曼哈顿距离：城市街区距离
    • 闵可夫斯基距离：通用公式

  3. K值选择

    • K太小：过拟合
    • K太大：欠拟合
    • 通过交叉验证选择最优K

  4. 特征预处理

    • 归一化：映射到[0,1]
    • 标准化：转换为均值为0，标准差为1
    • KNN必须做特征标准化

  5. 交叉验证和网格搜索

    • 交叉验证：评估模型稳定性
    • 网格搜索：寻找最优超参数

  2. 计算题： 给定以下数据，使用KNN（K=3，欧氏距离）预测未知样本的类别：

    请计算X到各训练样本的距离，并给出预测结果。

  3. 简答题： 为什么KNN算法必须做特征标准化？如果不做会怎样？

  4. 简答题： 比较归一化和标准化的区别，分别适用于什么场景？

编程题

  1. 从零实现KNN： 不依赖sklearn，从零实现一个KNN分类器，要求：

    • 支持欧氏距离和曼哈顿距离
    • 支持分类和回归
    • 在鸢尾花数据集上测试

  2. 鸢尾花分类： 使用sklearn的KNN API完成鸢尾花分类，要求：

    • 进行特征标准化
    • 使用网格搜索选择最优K值
    • 输出最优参数和准确率

  3. 对比实验： 比较不同K值（1, 3, 5, 7, 9, 11）在鸢尾花数据集上的表现，绘制K值-准确率曲线。

思考题

  1. 思考题： KNN算法的”训练”阶段和”预测”阶段分别做了什么？为什么说KNN是”惰性学习”？

  2. 思考题： 如果特征维度很高（如1000维），KNN会遇到什么问题？如何解决？

  3. 思考题： 对比KNN和你在深度学习中学到的RNN，它们各自适合什么场景？为什么？

错误3：K值选择为偶数

问题： K=4时可能出现2:2平局

解决： 选择奇数K值，如3, 5, 7

错误4：数据量太大

问题： KNN预测时需要计算与所有训练样本的距离，数据量大时很慢

解决：

  • 使用近似最近邻算法（如KD-Tree、Ball-Tree）
  • 降维（PCA）
  • 考虑其他算法（如决策树、SVM）
