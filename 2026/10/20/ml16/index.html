1. 什么是朴素贝叶斯

1.1 一个生活例子

假设你在水果摊挑西瓜，你观察到：

你的大脑会根据以往吃瓜的经验快速判断：”这瓜大概率是好瓜！”

朴素贝叶斯做的就是这件事：

💡 核心思想：根据已有的训练数据，计算”在观察到这些特征的前提下，属于某个类别”的概率，然后选概率最大的那个类别。

它和 KNN、决策树一样，是一类经典的监督学习算法（有标签），主要用于分类。

1.2 为什么叫”朴素”？

因为它做了一个很傻很天真（朴素）的假设：

⚠️ 特征条件独立假设：所有特征之间相互独立，互不影响。

放到挑瓜的例子里，就是假设”色泽”和”根蒂”毫无关系、”敲声”和”纹理”毫无关系……

这显然不完全符合现实（好瓜的青绿往往伴随蜷缩根蒂），但奇妙的是：

💡 StatQuest 的评价：这个假设虽然”naive”，但在实践中效果出奇地好！尤其是文本分类（垃圾邮件识别、情感分析），词与词之间当作独立处理，依然能拿到很高的准确率。

为什么有效？因为：

  1. 它只需要估计每个特征单独的概率，参数极少，不容易过拟合
  2. 分类只关心哪个类别概率最大，不要求概率本身精确

2. 数学基础：贝叶斯公式（图解）

2.1 先看一个直观的例子

📖 《白话机器学习的数学》的经典思路：把概率理解为”确信程度“，贝叶斯公式就是”根据新证据更新确信程度“。

假设：

  • 你一开始觉得”今天下雨”的概率是 20%（先验）
  • 你抬头看到满天乌云（新证据）
  • 你会怎么调整？”乌云”这证据太有说服力了 → 你把概率上调到 80%（后验）

贝叶斯公式就是把这件事用数学写出来。

2.2 贝叶斯公式

每个符号的含义：

符号 读法 大白话
$P(Y)$ 先验概率 没看到证据前，Y 发生的概率（比如”好瓜占 47%”）
$P(X\ Y)$ 似然 已知 Y 成立时，观察到 X 的概率（”好瓜里”有多少是青绿蜷缩）
$P(X)$ 证据因子 X 本身有多常见，起归一化作用
$P(Y\ X)$ 后验概率 看到证据 X 后，Y 成立的概率 —— 这是我们真正想要的

💡 一句话记忆：后验 = 先验 × 似然 / 证据

💡 关键技巧：分母 $P(X)$ 对所有类别都一样，所以比较时直接忽略它，只比较分子 $P(Y) \cdot P(X|Y)$，大大简化计算。这就是为什么朴素贝叶斯预测速度快。

3.1 从贝叶斯到朴素贝叶斯：一步”朴素”的化简

对一条有 $d$ 个特征的样本 $x = (x_1, x_2, \dots, x_d)$，精确的似然是联合概率：

难点在于：要估计所有特征的组合概率，特征多时组合数指数爆炸，训练数据根本覆盖不过来。

“朴素”假设登场——假设特征之间相互独立，联合概率变成简单连乘：

💡 大白话：把”这么多特征同时出现的概率”拆成”每个特征单独出现的概率相乘”。这就是朴素贝叶斯（Naive Bayes）名字的由来。

3.2 朴素贝叶斯预测公式

对样本 $x$，预测它属于后验概率最大的类别：

  • $\hat{y}$：预测的类别
  • $c$：遍历每个候选类别
  • $P(c)$：先验（训练集中 c 类样本的比例）
  • $P(x_j|c)$：条件概率（训练集 c 类样本中，第 j 个特征等于 $x_j$ 的比例）
  • $\arg\max$：返回使括号内值最大的那个 c

3.4 遇到零概率怎么办？—— 拉普拉斯修正

⚠️ 致命问题：如果训练集中”好瓜”里从没有过”纹理=模糊”，那么 $P(\text{模糊}|\text{好瓜}) = 0$，一连乘整个概率全部归零！这一个”从没见过”的特征，就把好瓜的概率一刀清零了。

拉普拉斯修正（Laplace Correction / 平滑）：给分子和分母各加一点”虚样本”：

  • $N$：类别总数（如好瓜/坏瓜两类 → N=2）
  • $N_j$：第 j 个特征的取值种类数（如”色泽”有 3 种取值 → $N_j = 3$）

为什么有效？

  • 计数从 0 变成 $\frac{0+1}{|D_c| + N_j}$，是一个很小但非零的值
  • 训练集很大时，+1 的影响微乎其微；训练集很小时，它防止某类概率被清零
  • 每个类别、每个取值都加了 1，依然保证所有类别的概率和为 1

💡 StatQuest 的比喻：就像给每个结果都”白送一票”，没人会是零票，避免一票定生死。

3.5 连续特征怎么办？——高斯朴素贝叶斯

如果特征是连续数值（如密度、含糖率），不能”数频率”。西瓜书给出两种做法：

做法一（简单）：把连续值离散化（分箱），当作类别处理。

做法二（常用）：假设特征服从高斯（正态）分布，用概率密度代替概率：

  • $\mu{c,j}$、$\sigma{c,j}^2$：训练集中类别 c 的样本在第 j 个特征上的均值和方差

计算示例：某类别下特征”含糖率”的均值 $\mu=3$、方差 $\sigma^2=4$，新样本 $x=5$：

这就是 sklearn GaussianNB 的核心假设。

__init__（初始化）

  • alpha：平滑系数。alpha=1.0 就是西瓜书的拉普拉斯修正；alpha=0 则退化为不做平滑（会碰到零概率问题）

fit（训练）—— 核心是”数频率”

  • self.classes_ = np.unique(y)：提取所有类别标签，比如 ['坏瓜', '好瓜']
  • n_samples, n_features = X.shape：X 是 (17, 6) 的矩阵 → 17 条样本、6 个特征
  • X[y == c]：布尔索引，巧妙地把某一类别的样本全部筛出来（例如 8 条好瓜）
  • np.unique(X_c[:, j], return_counts=True)：对第 j 列统计取值及其次数，例如 (['乌黑','青绿','浅白'], [4,2,2])
  • N_j = len(np.unique(X[:, j]))：特征取值数（在全集上统计！如”色泽”有 3 种）
  • 拉普拉斯修正公式 (cnt + alpha) / (Nc + N_j * alpha)：分子是计数+1，分母是该类样本数+特征取值数
  • 🔑 容易忽略的细节：还要遍历全集的取值，给”没见过”的取值补概率，否则预测时遇到新取值会 KeyError

predict_proba（计算联合概率）

  • 外层循环每个测试样本，内层循环每个类别
  • s = self.prior_[c]：从先验开始（对应公式 $P(c)$）
  • s *= self.cond_prob_[c][j][v]：逐特征连乘（对应 $\prod_j P(x_j|c)$）
  • ⚠️ 注意这里没有除以 $P(X)$——因为比较大小时分母相同，省掉它既正确又快

predict（预测）

  • max(r, key=r.get)：对每个样本返回概率最大的类别名，key=r.get 表示”按字典的值比较”

5. sklearn 中的朴素贝叶斯

scikit-learn 提供了三种朴素贝叶斯，区别在于对 $P(x_j|c)$ 的假设不同，对应不同类型的数据：

类 适用数据 条件概率假设 典型场景
GaussianNB 连续值 高斯分布 身高体重、密度含糖率
MultinomialNB__ 计数 多项式分布 词频 / TF-IDF 文本分类
BernoulliNB 二值（0/1） 伯努利分布 词是否出现（不关心次数）

5.1 GaussianNB（高斯朴素贝叶斯）

输出（已运行核验）：

常见属性：

  • gnb.theta_：每个类、每个特征的均值 $\mu$
  • gnb.var_：每个类、每个特征的方差 $\sigma^2$

💡 大白话：GaussianNB 训练就是给每个类别画几个高斯钟形曲线，预测时看新样本落在哪一类的曲线下面密度更高。

5.2 MultinomialNB（多项式朴素贝叶斯）

特征是”计数”（某词出现几次）时使用，是文本分类的头号主力。

输出（已运行核验）：

关键参数：

  • alpha：平滑系数（默认 1.0，即拉普拉斯修正）。文本分类必加，否则遇到测试集中没见过的词会零概率
  • mnb.feature_log_prob_：每个词在每个类别下的对数概率（取 np.exp 可还原）

6.4 进阶改进清单

改进 做法 收益
分词 中文用 jieba，英文按空格 词表更有语义，准确率显著提升
加权 TfidfVectorizer 替代词频 降低”的、了”等高频无义词的影响
停用词 去掉标点、虚词 减少噪声特征

调 alpha 网格搜索 0.1 / 0.5 / 1.0 微调平滑强度

7. 优缺点与适用场景

7.1 优点

  1. 训练和预测都极快：训练是”数频率”查表式操作，预测是少量乘法（sklearn 内部用对数加法）
  2. 小数据也能跑：参数少，不需要海量数据就能收敛
  3. 对缺失值天然友好：某个特征缺失，连乘里直接跳过即可
  4. 适合高维稀疏数据：文本动辄上万维特征，朴素贝叶斯依然从容
  5. 输出概率而非硬标签：predict_proba 能给出”多确定”，可用于排序、阈值调优

7.2 缺点

  1. “朴素”假设过强：特征之间存在强相关时（如图像相邻像素），效果差
  2. 条件概率常被低估：连乘导致后验概率偏小且”过度自信”（如 1e-194），适合比较排序，不适合当作真实概率
  3. 零概率敏感：必须做平滑（已由 alpha 参数保护）
  4. 对输入特征表示敏感：用错模型（如对连续数据硬用 MultinomialNB）效果骤降

💡 西瓜书视角：朴素贝叶斯的”朴素”（属性条件独立）几乎必然不成立，但它只需要估计一维条件概率，回避了估计联合分布的”维数灾难”，这是它在实践中有效的根本原因。

7.3 适用场景

  • ✅ 文本分类（垃圾邮件、情感分析、新闻打标签）—— 首选基线
  • ✅ 特征多、样本少的高维稀疏场景
  • ✅ 需要概率输出或快速原型的场景
  • ❌ 特征强相关、需精确建模组合特征（用决策树/集成学习）
  • ❌ 图像等空间结构数据（假设与事实严重背离）

8. 与其他算法对比

算法 类别 输出 优点 缺点 适用场景
朴素贝叶斯 生成模型 概率 快、稳、可解释、小数据可用 独立性假设过强 文本分类、基线模型
KNN 判别模型 硬标签 无需训练、直观 预测慢、需调 K、对尺度敏感 小数据原型
逻辑回归 判别模型 概率 可解释、正则化灵活 只能线性分割 点击率预估、风控
决策树 判别模型 硬标签 可解释性最强、能处理组合特征 易过拟合 特征交互明确的场景
集成学习 判别模型 概率 精度通常最高 训练慢、黑盒 比赛、追求精度

💡 生成模型 vs 判别模型（西瓜书 §7.1）：朴素贝叶斯的”野心”更大——它试图建模 $P(x, y)$ 的联合分布（数据是怎么生成的），再从中推出 $P(y|x)$；而 KNN/逻辑回归只直接学 $P(y|x)$。生成模型可以利用无标签数据，但也承担了更强的假设风险。

9. 小结

核心概念

  1. 朴素贝叶斯 = 贝叶斯公式 + 特征独立假设
  2. 贝叶斯公式：后验 = 先验 × 似然 / 证据
  3. 预测规则：$\hat{y} = \arg\max_c \left[ P(c) \prod_j P(x_j|c) \right]$（忽略分母）
  4. 参数估计：全部靠”数频率”，无迭代优化
  5. 拉普拉斯修正：$(\text{计数}+1) / (\text{总数}+\text{取值数})$，专治零概率清零
