深度学习基础：标准化与归一化的区别、原理及代码实现

在深度学习和机器学习的数据预处理阶段，**标准化（Standardization）与归一化（Normalization）**是两个极易混淆的概念。

一、 核心数学定义与区别

从严格的数学定义来看，两者的目标不同：

  • 归一化（Normalization）：将数据按比例缩放，使其落入一个特定的固定区间（通常是 [0, 1] 或 [-1, 1]）。
  • 标准化（Standardization）：将数据转换为均值为 0、标准差为 1 的分布（即 Z-Score 变换），使其符合标准正态分布。

1. 公式与特性对比

对比项 归一化 (Min-Max Scaling) 标准化 (Z-Score Normalization)
核心公式 (X’ = \frac{X - X_{min}}{X_{max} - X_{min}}) (X’ = \frac{X - \mu}{\sigma})
参数含义 (X_{min}) 与 (X_{max}) 分别为数据的最小值和最大值 (\mu) 为均值，(\sigma) 为标准差
输出范围 有严格边界，如 [0, 1] 无严格边界，数值通常在 [-3, 3] 之间
异常值敏感度 极高（极值直接决定上下界，异常值会压缩正常数据） 较低（均值和方差受异常值影响相对较小）
分布形状 改变原始分布形状 不改变原始分布形状，仅改变位置和尺度

2. 为什么需要这些处理？

在神经网络中，如果输入特征的量纲差异巨大（例如特征A范围为 0-1，特征B范围为 0-100000），损失函数的等高线会呈现狭长的椭圆形。在反向传播和梯度下降时，模型参数会在“峡谷”两侧来回震荡，导致收敛极其缓慢。

  • 归一化：适用于数据分布有明显边界的情况（如图像像素值天然在 0-255 之间）。
  • 标准化：适用于数据分布无明显边界，或存在极端异常值的情况（如身高、体重、金融数据等）。

二、 深度学习及 PyTorch 中的代码实现

在实际工程中，两者的代码映射与数学定义基本一致。但在 PyTorch 中，由于英文语境下“Normalize”常被泛化使用，存在一些需要特别注意的命名差异。

1. 真正执行“归一化”（Min-Max）的函数

  • 图像处理中的 ToTensor()：torchvision.transforms.ToTensor() 会将图像像素值从 [0, 255] 除以 255，缩放至 [0.0, 1.0]。
  • 激活函数中的 Sigmoid 和 Softmax：nn.Sigmoid() 将输出压缩至 (0, 1) 区间；nn.Softmax(dim=1) 将多分类输出转化为概率分布（每项在 0-1 之间，且和为 1）。这属于非线性归一化。
  • 手动实现：直接使用 (X - X.min()) / (X.max() - X.min())。
  • 传统机器学习库：sklearn.preprocessing.MinMaxScaler。

2. 真正执行“标准化”（Z-Score）的函数

  • 图像预处理中的 transforms.Normalize()：在 torchvision 中，它执行的是 (X’ = \frac{X - mean}{std})，是标准的 Z-Score 标准化。通常与 ToTensor() 配合使用：先归一化到 [0, 1]，再标准化到 [-1, 1]。
  • 网络层中的 nn.BatchNorm1d/2d（批归一化）：尽管中文名为“批归一化”，但其内部逻辑是严格的数据标准化。它计算当前批次的均值 (\mu) 和方差 (\sigma^2)，执行 ((X - \mu) / \sqrt{\sigma^2 + \epsilon})，并在此基础上进行可学习的缩放（(\gamma)）和平移（(\beta)）。
  • 网络层中的 nn.LayerNorm（层归一化）：与 BatchNorm 类似，同样执行的是标准化操作，常用于 RNN 和 Transformer。
  • 传统机器学习库：sklearn.preprocessing.StandardScaler。

可见深度学习的命名机制不够严格，部分归一化的操作其实是标准化

三、 总结

鉴于 PyTorch 中命名习惯与中文翻译存在的差异，建议通过公式核心特征来区分：

看到 “Mean / Std”（减去均值除以标准差）即为标准化；
看到 “Min / Max”（减去最小值除以极差）或 “0-1” 区间即为归一化。

名称 核心特征 常见代码代表 深度学习常见场景
归一化 缩放到固定区间，受极值影响大 ToTensor(), Sigmoid, Softmax, MinMaxScaler 图像像素预处理、分类模型输出层的概率转化
标准化 均值 0，方差 1，受极值影响小 transforms.Normalize, nn.BatchNorm, nn.LayerNorm, StandardScaler 特征输入预处理、网络中间层（BN层）的输出规范化
