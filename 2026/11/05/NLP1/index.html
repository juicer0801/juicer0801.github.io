三种分词模式对比
  1. 🎯 精确模式（默认）
    特点：试图将句子最精确地切开，不存在冗余，适合文本分析、情感分析等场景。

要点：cut_all=False 是默认值，也可以直接写 jieba.cut(text)。

  1. 🌐 全模式
    特点：把句子中所有可能成词的词语都扫描出来，速度很快，但会产生歧义和冗余，不适合直接作为最终分词结果。

观察：在全模式下，“清华大学”被拆出了“清华”“华大”“大学”等多种组合，信息更全，但噪声也更多。

  1. 🔍 搜索引擎模式
    特点：在精确模式的基础上，对长词再次切分，提高召回率，适合搜索引擎构建倒排索引。

观察：它先把“清华大学”当成一个整词，再额外补上“清华”“华大”“大学”这些子词，既保留了精确模式的完整词，又增加了细粒度的召回项。换一个更明显的例子：

“中国科学院”被拆出“中国”“科学”“学院”“科学院”等下级词，搜索引擎模式下长词召回率明显提高。

  1. 🧠 Paddle 模式（深度学习模式）
    特点：利用 PaddlePaddle 训练的双向 GRU 序列标注网络进行分词，同时支持词性标注；对未登录词、整体性较强的专有名词往往有更好的切分效果。需要 jieba ≥ 0.40，并安装 paddlepaddle-tiny。

与精确模式的对比：

模式 “西北皇家理工学院”的切分结果
精确模式 西北 / 皇家 / 理工学院
Paddle 模式 西北皇家理工学院（整体保留）

Paddle 模式把这个长专有名词作为一个整体切了出来，而传统精确模式把它切成了多个片段。

注意：paddlepaddle-tiny 对 Python 版本的支持有限，较新 Python 环境可能无法直接使用 Paddle 模式。

  1. 一表速查
模式 调用方式 核心逻辑 典型用途
精确模式 jieba.cut(text) 最精确切分，无冗余 文本分析、分类、情感分析
全模式 jieba.cut(text, cut_all=True) 扫描所有可能成词 快速候选词生成、词典构建辅助
搜索引擎模式 jieba.cut_for_search(text) 精确模式 + 长词二次切分 搜索引擎倒排索引、召回场景
Paddle 模式 jieba.cut(text, use_paddle=True) 双向 GRU 深度学习模型 专有名词、未登录词较多的场景

命名实体识别

文本处理的基本方法 – 分词、命名实体识别、词性标注 - 8

  • 命名实体识别 - 概念
  • 命名实体: 将人名, 地名, 机构名等专有名词统称命名实体。如: 周杰伦, 黑山县, 孔子学院, 24辊方钢矫直机
  • 命名实体识别：(Named Entity Recognition，简称NER)，识别出一段文本中可能存在的命名实体

  • 作用：命名实体也是人类理解文本的基础单元，是AI解决NLP领域高阶任务的重要基础环节

  • 命名实体识别 – 栗子
    鲁迅，浙江绍兴人，五四新文化运动的重要参与者，代表作朝花夕拾。
    ==> 鲁迅(人名) / 浙江绍兴(地名)人 / 五四新文化运动(专有名词) / 重要参与者 / 代表作 / 朝花夕拾(专有名词)

词性标注

文本处理的基本方法 – 分词、命名实体识别、词性标注 - 9

  • 词性标注 – 概念
  • 词性: 语言中对词的一种分类方法，以语法特征为主要依据、兼顾词汇意义对词进行划分的结果
    常见的词性有14种, 如: 名词, 动词, 形容词等
  • 词性标注：(Part-Of-Speech tagging, 简称POS)，标注出一段文本中每个词汇的词性
  • 词向标注作用：对文本语言的另一个角度的理解，AI解决NLP领域高阶任务的重要基础环节
  • 词性标注 – 栗子
    我爱自然语言处理
    ==>
    我/rr, 爱/v, 自然语言/n, 处理/vn
    rr: 人称代词
    v: 动词
    n: 名词
    vn: 动名词

总结

1 分词定义、作用、中文为什么要分词?
• 概念：将连续字符按照一定规则重新排序的过程。
• 作用： 理解语义的最小单元，是NLP高阶任务的基础
• 中文为什么要分词：因中文句子没有天然分隔符

2 jieba编程api？
• 三种分词模式
• jieba.lcut(content, cut_all=False) 精确模式，默认模式
• jieba.lcut(content, cut_all=True) 全模式
• jieba.cut_for_search(content) 搜素引擎模式
• 用户字典
• jieba.load_userdict(‘./userdict.txt’)
• mydata2 = jieba.lcut(sentence)

3 命名实体识别NER ?
• 命名实体：指人名地名机构名等专有名字
• 命名实体识别NER：对一句话中的专有名词进行识别(NER - Named Entity
Recognition)
• 作用：理解语义的最小单元，是NLP高阶任务的基础

4 什么是词性标注POS，jieba的api支持？
• 词性：句子中的动词、名词、形容词等
• 词向标注：Part-Of-Speech tagging, 简称POS，标注出一段文本每个词的词性
• 词性标注作用：理解语义的最小单元，是NLP高阶任务的基础
• 注意：词向标注是单词级别的分类
• import jieba.posseg as pseg
• pseg.lcut(“我爱北京天安门”)
