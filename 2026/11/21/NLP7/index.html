1 案例介绍

  • 关于人名分类问题:

以一个人名为输入, 使用模型帮助我们判断它最有可能是来自哪一个国家的人名, 这在某些国际化公司的业务中具有重要意义, 在用户注册过程中, 会根据用户填写的名字直接给他分配可能的国家或地区选项, 以及该国家或地区的国旗, 限制手机号码位数等等.

  • 人名分类数据预览

  • 数据存放路径：$(home)/data/name_classfication.txt

  • 数据格式说明 每一行第一个单词为人名，第二个单词为国家名。中间用制表符tab分割

• 根据人名预测是哪一个国家（18个国家）
• 典型就是一个分类问题；AI赋能互联网行业-提高业务效率
• 文本数值化和数值张量化的技术选型分析（数据如何送给模型？）
• 比如：每个姓氏构成一个单词：“zhang”、“wang”、“li”、 ‘Weston’ 等等，需要转成张量送给模型
• 技术路线1：以单词为单位，word2id后送给RNN模型抽取事物特征进行分类。这样每个姓氏只能整体送1次。
• 技术路线2：比如：z-h-a-n-g以字母为单位，送给RNN模型抽取事物特征进行分类。
• 本案例：文本数值化方案采用：技术路线2：以字母为单位，进行文本数值化和数值张量化
比如：一共有57个字母，构成字母表。每个字母进行one-hot编码，再送给RNN模型

• 短文本分类，模型选型分析 （如何选模型？）
• 模型可以选中RNN、LSTM、GRU，分别测试三个模型的准确率、损失下降情况、训练时间等等
• 综合对比三个模型在数据集的表现，选择合适的模型

疑问解答

1. x 是怎么来的，形状是什么？

在你的代码中，使用 DataLoader 时设置了 batch_size=1：

  • 当 DataLoader 遍历数据集时，即使 batch_size=1，它也会默认在最前面加一个批次（batch）维度。
  • 假设当前取出的名字是 "Alexander"（长度10），Dataset 返回的形状本来是 [10, 57]（序列长度 10，特征维度 57）。
  • 经过 DataLoader 后，x 的形状变成了 [1, 10, 57] （即 [batch_size, seq_len, input_size]）。

2. 为什么模型需要 x[0]？

看你的自定义 RNN 类的 forward 函数：

  • 模型在 forward 里，期望传进来的 input 是 2维的 [seq_len, 57]（比如 [10, 57]），然后再通过 input.unsqueeze(1) 自己手动把 batch 维度加回来，变成 [10, 1, 57]，这样才能喂给 PyTorch 底层的 nn.RNN。
  • 如果你直接把 x (形状 [1, 10, 57]) 传进去，经过 unsqueeze(1) 就会变成 [1, 1, 10, 57]，这就变成了 4 维张量，nn.RNN 会直接报错。
  • 因此，x[0] 的作用就是把形状为 [1, 10, 57] 的 x 降维，取出第 0 个 batch，得到 [10, 57]。

3. 为什么调用官方 nn.LSTM 时必须加括号？

在 PyTorch 官方底层的 nn.LSTM 设计中，它的隐藏状态是一个包含两个张量的元组 (h_n, c_n)。
看你的 LSTM 类的 forward 方法：

  • 这里 (hidden, c) 加括号，是为了把这两个独立的张量打包成一个元组，喂给官方底层的 C++ 实现。
  • 同时，官方返回的结果也是打包好的 output, (hn, cn)，左边的 (hn, cn) 就是在做解包操作，把元组里的两个值分别赋给 hn 和 cn。

4. 为什么自定义的 forward 接收参数时不加括号？

看你的自定义类的定义：

  • 作者在设计这个自定义 LSTM 模型时，选择把 hidden 和 c 作为两个独立的参数传进来，而不是作为一个元组传进来。
  • 这样做的好处是：调用起来更直观，不需要在外部写 my_lstm(x, (h, c)) 这样两层括号。
  • 所以在测试代码中，调用是这样的：my_lstm(x[0], hidden, c)，这里不加括号，直接把两个变量传进去。

5. 为什么返回值有时候加，有时候不加？

看你的 forward 的返回值：

  • 这里没有加括号，但它在 Python 里实际上返回的依然是一个元组。
  • 在 Python 中，逗号 , 才是元组的标志。return a, b, c 完全等价于 return (a, b, c)。加括号只是为了视觉上更清晰，但在语法上不强制。
  • 所以在测试代码接收时，直接写 output, hidden, c = my_lstm(...) 就可以按位置一一对应解开。
