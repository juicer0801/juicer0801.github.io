首先windows需要手动安装vim

以下按功能分类列举常用 Vim 操作，默认在 Normal 模式 下。Ctrl- 表示按住 Ctrl。

模式切换
i：光标前插入

I：行首插入

a：光标后插入

A：行尾插入

o：下方新建行插入

O：上方新建行插入

v：字符可视模式

V：行可视模式

Ctrl-v：块可视模式

R：替换模式

Esc / Ctrl-[：返回 Normal 模式

:：命令行模式

/、?：搜索模式

光标移动
h j k l：左 下 上 右

w / b：下一个 / 上一个单词开头

e / ge：下一个 / 上一个单词结尾

0 / ^ / $：行首 / 第一个非空字符 / 行尾

gg / G：文件开头 / 文件结尾

nG 或 :n：跳到第 n 行

f{char} / F{char}：向后 / 向前查找字符

t{char} / T{char}：到字符前 / 后

; / ,：重复 / 反向重复 f/t

%：匹配括号跳转

{ / }：上 / 下段落

( / )：上 / 下句子

H / M / L：屏幕顶 / 中 / 底

Ctrl-f / Ctrl-b：下 / 上翻页

Ctrl-d / Ctrl-u：下 / 上半页

zt / zz / zb：当前行置顶 / 中 / 底

  • / #：搜索光标下单词，向后 / 向前

编辑与删除
x / X：删除光标处 / 前一个字符

dd：删除整行

D：删除到行尾

dw / de：删除到下一个单词 / 单词尾

d0 / d$：删除到行首 / 行尾

dgg / dG：删除到文件头 / 尾

s：删除字符并插入

S 或 cc：删除整行并插入

C：删除到行尾并插入

r：替换单个字符

~：切换大小写

J：合并下一行，带空格

gJ：合并下一行，不带空格

/ <<：右 / 左缩进

=：自动缩进

gg=G：全文自动缩进

Ctrl-a / Ctrl-x：数字加一 / 减一

u：撤销

Ctrl-r：重做

U：撤销对当前行的所有修改

.：重复上次修改

复制、粘贴、寄存器
yy / Y：复制整行

yw：复制单词

y$：复制到行尾

yG：复制到文件尾

p / P：光标后 / 前粘贴

“+y / “+p：复制到 / 粘贴系统剪贴板

“_dd：删除到黑洞寄存器，不覆盖剪贴板

“0p：粘贴最近复制内容

“aY / “ap：复制到 / 粘贴寄存器 a

:reg：查看寄存器

搜索与替换
/pattern：向下搜索

?pattern：向上搜索

n / N：下一个 / 上一个匹配

:noh：取消搜索高亮

:s/old/new/：当前行替换第一个

:s/old/new/g：当前行全部替换

:%s/old/new/g：全文替换

:%s/old/new/gc：全文替换并确认

:n,m s/old/new/g：第 n 到 m 行替换

:g/pattern/d：删除匹配行

:v/pattern/d：删除不匹配行

:%s/\s+$//e：删除行尾空格

文本对象
可配合 d、c、y、v 使用：

iw / aw：单词内 / 一个单词

i” / a”：双引号内 / 含双引号

i’ / a’：单引号内 / 含单引号

i( / a(：括号内 / 含括号

i{ / a{：花括号内 / 含花括号

it / at：标签内 / 含标签

ip / ap：段落内 / 含段落

例：diw 删除单词，ci” 修改双引号内容，ya{ 复制花括号块

可视模式
v / V / Ctrl-v：字符 / 行 / 块选择

o：切换选择活动端

gv：重选上次可视区域

d / y / c：删除 / 复制 / 修改选中

/ <：缩进 / 反缩进

~ / U / u：切换大小写 / 大写 / 小写

块选择下 I / A：多行同时插入 / 追加

:’<,’>s/old/new/g：对选中行替换

文件、保存、退出
:w：保存

:q：退出

:wq：保存退出

:x：保存退出，未修改则直接退出

ZZ：保存退出

:q!：强制退出不保存

ZQ：强制退出不保存

:e file：编辑文件

:saveas newfile：另存为

:r file：读入文件内容

:w !sudo tee %：用 sudo 保存当前文件

:bn / :bp：下一个 / 上一个缓冲区

:bd：关闭缓冲区

:ls：列出缓冲区

窗口与标签
:sp / :vsp：水平 / 垂直分屏

Ctrl-w h/j/k/l：切换窗口

Ctrl-w q：关闭当前窗口

Ctrl-w o：只保留当前窗口

Ctrl-w =：等宽等高

:tabnew：新建标签页

gt / gT：下一个 / 上一个标签页

:tabclose：关闭标签页

宏与标记
qa：开始录制宏到寄存器 a

q：停止录制

@a：播放宏 a

@@：重复上次宏

ma：设置标记 a

`a：跳转到标记 a

‘a：跳转到标记 a 行首

``：上次跳转位置

‘.：最后修改位置

gi：上次插入位置并进入插入

Ctrl-o / Ctrl-i：跳转历史后退 / 前进

g; / g,：上一个 / 下一个修改位置

Shell 与命令
:!cmd：执行 shell 命令

:r !cmd：插入命令输出

:%!cmd：用命令过滤全文

:sh：进入 shell，exit 返回

:terminal：打开终端

:sort：排序

:help：帮助

:set nu / :set nonu：显示 / 隐藏行号

:set ic / :set noic：忽略 / 区分大小写

:set hls / :set nohls：搜索高亮开 / 关

:set paste / :set nopaste：粘贴模式开 / 关

:set list：显示不可见字符

:set wrap / :set nowrap：自动换行开 / 关

折叠
zf：创建折叠

zo / zc：打开 / 关闭折叠

za：切换折叠

zR / zM：打开 / 关闭所有折叠

高频组合
ggVG：全选

gg=G：全文缩进

:%y+：全文复制到系统剪贴板

:set paste 后粘贴，再 :set nopaste：避免自动缩进

qa … q @a：录制并播放宏

:g/^$/d：删除所有空行

:s/old/new/gc：当前行确认替换
