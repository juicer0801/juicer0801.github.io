标量，向量，矩阵，张量，轴，维度

文章发布时间:
2026-09-26

最后更新时间:
2026-09-26

其实在深度学习里，张量就是多维数组。

从标量到张量
标量：就是一个数。
比如 3.0、5。它是 0 维张量，形状是 ()。你可以理解成一个点。

向量：一排数。
比如 [1, 2, 3]。它是 1 维张量，形状是 (3,)。你可以理解成一条线。

矩阵：一张表，有行有列。
比如
[[1, 2],
[3, 4]]
它是 2 维张量，形状是 (2, 2)。你可以理解成一张表格。

张量：不是只指三维以上。标量、向量、矩阵，全都是张量。张量是总称。0 维叫标量，1 维叫向量，2 维叫矩阵，3 维、4 维、n 维，统一叫张量。

所以关系是：
标量 = 0 维张量
向量 = 1 维张量（具有一个轴）
矩阵 = 2 维张量（具有2个轴）
更高维 = n 维张量
张量 = 所有这些的总称

在代码里
一维是列表，二维是列表套列表，三维是列表套列表套列表。

轴是什么？
轴，英文叫 axis，PyTorch 里也常叫 dim。
轴就是维度的编号。编号从 0 开始。

比如一个矩阵形状是 (2, 3)：
x = torch.tensor([[1, 2, 3],
[4, 5, 6]])
x.shape # torch.Size([2, 3])

这里有两个轴：
axis=0 是第 0 轴，长度是 2，也就是行方向。
axis=1 是第 1 轴，长度是 3，也就是列方向。

注意：轴不是“行”或“列”本身，而是那个维度的位置。二维的时候你可以粗略记成 axis=0 是行，axis=1 是列。三维以上，就不能死记了，得看形状。

再看一个三维张量：
x = torch.arange(24).reshape(2, 3, 4)
x.shape # torch.Size([2, 3, 4])

它有 3 个轴：
第 0 轴长度 2
第 1 轴长度 3
第 2 轴长度 4

轴的数量 = 维度数 = len(x.shape)。
所以这个张量是 3 维张量。

沿轴操作，是什么意思？
你记住一句话：沿哪个轴操作，哪个轴就消失。

比如二维张量：
x = torch.tensor([[1, 2, 3],
[4, 5, 6]])

x.sum(axis=0) # tensor([5, 7, 9])，形状 (3,)
x.sum(axis=1) # tensor([6, 15])，形状 (2,)
axis=0 求和，是把行方向压掉，剩下每一列的和。
axis=1 求和，是把列方向压掉，剩下每一行的和。

三维也一样：
x = torch.arange(24).reshape(2, 3, 4)

x.sum(axis=0).shape # (3, 4)
x.sum(axis=1).shape # (2, 4)
x.sum(axis=2).shape # (2, 3)
你沿哪个轴求和，哪个轴就没了。
如果想保留那个轴，长度变成 1，可以加 keepdim=True：

x.sum(axis=0, keepdim=True).shape # (1, 3, 4)
用生活里的东西比一下
标量：一个点。

向量：一排数，像一根线。

矩阵：一张表。

三维张量：一摞表。

四维张量：一摞表再叠起来，比如一批图片，形状常是 (batch, channel, height, width)。

轴就是“你从哪个方向看这堆数”。
沿轴操作，就是沿着那个方向把数聚合、压扁、求和、求平均。

张量是总称，标量、向量、矩阵都是张量。
标量 0 维，向量 1 维，矩阵 2 维，更高维都叫张量。
轴就是维度的编号，从 0 开始。
沿哪个轴操作，哪个轴就消失。

维度是啥？
在深度学习里，“维度”这个词有两个用法，小白最容易在这儿绕晕。

第一个用法：这个张量是几维的。
也就是它有几个轴。 x.shape，看到 torch.Size([2, 3, 4])，那它的维度数就是 3，叫三维张量。
代码里看 x.ndim，或者 len(x.shape)，得到的就是维度数。

第二个用法：某个轴的长度。
比如别人说“这个特征维度是 128”，他可能指的是某个轴的长度是 128，不是整个张量有 128 维。
看到“维度”两个字，先看上下文。

所以严格说：
维度数 = 有几个轴 = x.ndim
轴长度 = 某个方向有多长 = x.shape[axis]

拿 (2, 3, 4) 举例：
它是 3 维张量，因为 x.ndim = 3

第 0 轴长度是 2
第 1 轴长度是 3
第 2 轴长度是 4

维度和轴、形状的关系
你可以这么理解：

形状：每个方向有多长，比如 (2, 3, 4)

维度数：一共有几个方向，这里是 3

轴：方向的编号，从 0 开始，这里是 0、1、2
一个元素要几个下标才能定位，它就是几维。

标量：不用下标，x 就是它。0 维。

向量：一个下标，x[0]。1 维。

矩阵：两个下标，x[0][1] 或 x[0, 1]。2 维。

三维张量：三个下标，x[0, 1, 2]。3 维。

所以标量、向量、矩阵，都是张量，只是维度数不同。

怎么“添加维度”？
PyTorch 里加维度用 unsqueeze，意思是在指定位置插一个长度为 1 的轴。

import torch

x = torch.tensor([1, 2, 3])
print(x.shape) # torch.Size([3])
print(x.ndim) # 1

y = x.unsqueeze(0)
print(y.shape) # torch.Size([1, 3])
print(y.ndim) # 2

z = x.unsqueeze(1)
print(z.shape) # torch.Size([3, 1])
print(z.ndim) # 2
unsqueeze(0) 是在最前面加一个轴，变成 (1, 3)。
unsqueeze(1) 是在第 1 轴位置加一个轴，变成 (3, 1)。

也可以写成：

x[None, :] # 等价于 unsqueeze(0)，shape (1, 3)
x[:, None] # 等价于 unsqueeze(1)，shape (3, 1)
反过来，去掉长度为 1 的轴用 squeeze：

y = torch.tensor([[1, 2, 3]]) # shape (1, 3)
y.squeeze(0) # shape (3,)
注意：只有长度为 1 的轴才能被 squeeze 掉，长度不是 1 的轴不会动。

还有 keepdim=True，它在求和、求平均时保留那个轴，长度变成 1：

x = torch.tensor([[1, 2, 3],
[4, 5, 6]]) # shape (2, 3)

x.sum(axis=0).shape # (3,)
x.sum(axis=0, keepdim=True).shape # (1, 3)

为什么要加维度？

  1. 广播
    不同形状的张量运算时，PyTorch 会自动补维度。比如：

a = torch.tensor([1, 2, 3]) # (3,)
b = torch.tensor([[10], [20], [30]]) # (3, 1)
a + b # 结果是 (3, 3)
a 被当成 (1, 3)，b 被当成 (3, 1)，然后广播成 (3, 3)。手动 unsqueeze 是为了控制这个过程。

  1. 批量
    单张图片形状常常是 (C, H, W)，但模型通常要求一批图片 (N, C, H, W)。
    你只有一张，就加个 batch 维：x.unsqueeze(0)，变成 (1, C, H, W)。

  2. 对齐形状
    有些函数、层、运算要求输入必须是几维，加个长度为 1 的轴就能对上。

总之
维度数 = 有几个轴 = x.ndim。

轴长度 = 某个方向多长 = x.shape[axis]。

加维度用 unsqueeze，只是插一个长度为 1 的轴，不增加数据。

x.numel() 不会因为 unsqueeze 变多，元素总数不变。

张量是盒子，形状是盒子每边多长，维度数是盒子有几个方向，轴是方向的编号。

建议：
抛弃行列的思维，替代为0轴，1轴 这种多维空间表述
抛弃对形状的空间思维，（2，3，4） （2，）这些都是形状
