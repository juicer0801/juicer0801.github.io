用 XOR 异或问题，结构为 2 -> 4 -> 1，激活函数用 Sigmoid，损失用二元交叉熵。PyTorch 会自动完成反向传播，optimizer.step() 就是梯度下降。

对应关系：

  • y_pred = model(X)：前向传播
  • loss.backward()：反向传播，自动计算梯度
  • optimizer.step()：梯度下降，更新参数
  • p.grad：保存反向传播算出来的梯度

下面逐行解释 PyTorch 版代码

1. 导入库

  • import torch：导入 PyTorch 核心库，提供张量（Tensor）和自动求导机制。
  • import torch.nn as nn：导入神经网络模块，里面有 Linear、BCELoss 等层和损失函数。
  • import torch.optim as optim：导入优化器模块，比如 SGD、Adam，用来做梯度下降。

2. 准备数据

  • 定义输入数据 X，形状是 (4, 2)，表示 4 个样本，每个样本有 2 个特征。
  • 这 4 个样本就是 XOR 问题的四种输入组合：(0,0)、(0,1)、(1,0)、(1,1)。
  • dtype=torch.float32 指定为 32 位浮点数，因为 PyTorch 默认神经网络计算使用 float32。
  • 定义标签 y，形状 (4, 1)，对应 XOR 的输出：0, 1, 1, 0。
  • 注意这里用二维 (4,1) 而不是一维 (4,)，是为了和模型输出形状匹配。
  • 设置随机种子，保证每次运行结果可复现。
  • 因为后面 nn.Linear 初始化权重时会用到随机数。

3. 定义模型

  • 定义一个神经网络类 Net，继承自 nn.Module。
  • 所有 PyTorch 模型都要继承 nn.Module，这样才能使用自动求导、参数管理等功能。
  • __init__ 是构造函数，初始化网络层。
  • super().__init__() 调用父类 nn.Module 的初始化，必须写。
  • 定义第一个全连接层 fc1，输入维度 2，输出维度 4。
  • 内部包含权重 W1 形状 (4,2) 和偏置 b1 形状 (4,)（PyTorch 中 Linear 的权重是 (out_features, in_features)）。
  • 定义第二个全连接层 fc2，输入 4，输出 1。
  • 权重形状 (1,4)，偏置形状 (1,)。

nn.Linear 是什么？

nn.Linear(in_features, out_features) 创建一个全连接层，它对输入做线性变换：

[
y = x W^T + b
]

其中：

  • 输入 (x) 的形状是 (batch_size, in_features)
  • 权重 (W) 的形状是 (out_features, in_features)
  • 偏置 (b) 的形状是 (out_features,)
  • 输出 (y) 的形状是 (batch_size, out_features)

注意：PyTorch 把权重存成 (out_features, in_features)，而不是 (in_features, out_features)。所以计算时用的是 (x W^T)，而不是 (x W)。这样设计是为了方便批量矩阵乘法。

二、第一层：self.fc1 = nn.Linear(2, 4)

1. 参数含义

  • in_features = 2：每个输入样本有 2 个特征。对应 XOR 的输入 ((x_1, x_2))。
  • out_features = 4：这一层输出 4 个值，也就是隐藏层有 4 个神经元。

2. 权重和偏置的形状

  • 权重 W1：形状 (4, 2)，即 (out_features, in_features)。
    • 每一行对应一个隐藏神经元的 2 个权重。
    • 一共 4 行，所以有 (4 \times 2 = 8) 个权重。
  • 偏置 b1：形状 (4,)，即每个隐藏神经元一个偏置，共 4 个。

总参数量：(8 + 4 = 12)。

3. 前向传播计算

假设输入 X 的形状是 (4, 2)（4 个样本，每个 2 个特征）：

经过 fc1 时，实际计算是：

[
Z_1 = X \cdot W_1^T + b_1
]

维度变化：

  • X：(4, 2)
  • W1：(4, 2)
  • W1.T：(2, 4)
  • X @ W1.T：(4, 2) @ (2, 4) = (4, 4)
  • b1：(4,)，广播到每一行，变成 (4, 4)
  • 最终 Z1：(4, 4)

也就是说，每个样本从 2 维特征变成了 4 维隐藏表示。

4. 举例说明

假设 W1 和 b1 初始化后是某个具体值，对于第一个样本 [0, 0]：

[
Z_1^{(1)} = [0, 0] \cdot W_1^T + b_1 = b_1
]

因为输入是 0，所以输出就是偏置。对于其他样本，输入非零，就会加上权重的贡献。

之后会经过 sigmoid 激活函数，得到 A1 = sigmoid(Z1)，形状仍然是 (4, 4)。

三、第二层：self.fc2 = nn.Linear(4, 1)

1. 参数含义

  • in_features = 4：输入来自第一层的 4 个隐藏神经元输出。
  • out_features = 1：输出 1 个值，即最终的预测概率。

2. 权重和偏置的形状

  • 权重 W2：形状 (1, 4)，即 (out_features, in_features)。
    • 只有 1 行，对应输出神经元的 4 个权重。
    • 共 (1 \times 4 = 4) 个权重。
  • 偏置 b2：形状 (1,)，即输出神经元一个偏置。

总参数量：(4 + 1 = 5)。

3. 前向传播计算

输入是 A1，形状 (4, 4)（4 个样本，每个样本有 4 个隐藏特征）。

[
Z_2 = A_1 \cdot W_2^T + b_2
]

维度变化：

  • A1：(4, 4)
  • W2：(1, 4)
  • W2.T：(4, 1)
  • A1 @ W2.T：(4, 4) @ (4, 1) = (4, 1)
  • b2：(1,)，广播到每一行，变成 (4, 1)
  • 最终 Z2：(4, 1)

再经过 sigmoid 激活，得到 A2 = sigmoid(Z2)，形状 (4, 1)，就是每个样本的预测概率。

四、整个网络的数据流

把两层连起来看：

步骤 操作 形状变化
输入 X (4, 2)
第一层线性 Z1 = X @ W1.T + b1 (4, 2) @ (2, 4) -> (4, 4)
第一层激活 A1 = sigmoid(Z1) (4, 4)
第二层线性 Z2 = A1 @ W2.T + b2 (4, 4) @ (4, 1) -> (4, 1)
第二层激活 A2 = sigmoid(Z2) (4, 1)
输出 A2 (4, 1)
  • 输入 2 维，经过隐藏层扩展到 4 维，再压缩到 1 维输出。
  • 隐藏层的 4 个神经元提供了足够的非线性表达能力，使得网络可以拟合 XOR 这种线性不可分的问题。

五、为什么权重是 (out_features, in_features)？

这是 PyTorch 的设计约定。在数学上，线性变换通常写成：

[
y = xW + b
]

其中 (x) 是行向量，(W) 是 (in_features, out_features)。但 PyTorch 为了高效计算，把权重存成 (out_features, in_features)，前向传播时用 x @ W.T。这样：

  • 对批量输入 X 形状 (batch, in_features)，X @ W.T 直接得到 (batch, out_features)。
  • 不需要转置输入，计算更高效。

所以记住：PyTorch 中 Linear 的 weight 形状永远是 (out_features, in_features)，bias 形状是 (out_features,)。

六、参数量小结

层 输入维度 输出维度 权重形状 偏置形状 参数量
fc1 2 4 (4, 2) (4,) 8 + 4 = 12
fc2 4 1 (1, 4) (1,) 4 + 1 = 5
合计 17

这个网络虽然小，但已经足够学习 XOR 问题。通过反向传播和梯度下降，这 17 个参数会被不断调整，最终使输出接近 [0, 1, 1, 0]。

  • forward 方法定义前向传播的计算过程。
  • 当我们调用 model(X) 时，PyTorch 会自动调用 forward(X)。
  • 先经过 fc1 做线性变换：x @ W1.T + b1。
  • 然后通过 sigmoid 激活函数，引入非线性。
  • 结果形状 (4, 4)：4 个样本，每个样本得到 4 个隐藏层神经元输出。
  • 再经过 fc2 线性变换，得到 (4, 1)。
  • 最后用 sigmoid 把输出压缩到 (0, 1) 区间，表示概率。
  • 返回结果。
  • 返回最终的预测值。
  • 实例化模型，此时会初始化 fc1 和 fc2 的权重和偏置。

4. 损失函数和优化器

  • 定义损失函数为二元交叉熵损失（Binary Cross Entropy Loss）。
  • 因为输出层用了 sigmoid，输出是概率值，所以用 BCELoss 很合适。
  • 注意：BCELoss 要求输入已经是 (0,1) 之间的概率，且形状与标签一致。
  • lr = 0.5：学习率，控制梯度下降的步长。
  • optim.SGD：随机梯度下降优化器。
  • model.parameters()：把模型中所有需要训练的参数（fc1 和 fc2 的权重、偏置）交给优化器管理。
  • 优化器会在后续用 step() 更新这些参数。

5. 训练循环

  • 训练轮数，一共迭代 20000 次。
  • 因为数据量很小，需要较多轮才能收敛。
  • 循环 epochs + 1 次，多一次是为了在最后打印第 20000 轮的结果。
  • epoch 从 0 到 20000。

5.1 前向传播

  • 调用模型，执行 forward 方法，得到预测输出 y_pred，形状 (4,1)。
  • 这就是前向传播。
  • 用二元交叉熵计算预测值 y_pred 和真实标签 y 之间的损失。
  • loss 是一个标量张量，包含梯度信息。

5.2 清空旧梯度

  • 清空优化器中所有参数的梯度。
  • 因为 PyTorch 的梯度默认会累加，如果不清零，上一次的梯度会叠加到这一次，导致错误。
  • 所以每次反向传播前必须调用 zero_grad()。

5.3 反向传播

  • 反向传播，自动计算损失对每个参数的梯度。
  • PyTorch 会从 loss 开始，沿着计算图反向求导，把梯度存到每个参数的 .grad 属性中。
  • 例如 model.fc1.weight.grad 就是 W1 的梯度。

5.4 梯度下降

  • 根据优化器的规则更新参数。
  • 对于 SGD，更新公式是：param = param - lr * param.grad。
  • 这一步就是梯度下降。

5.5 打印损失

  • 每 2000 轮打印一次当前轮数和损失。
  • loss.item() 把标量张量转成 Python 浮点数，方便打印。
  • :6d 表示整数占 6 位，:6f 表示浮点数保留 6 位小数。

6. 预测结果

  • torch.no_grad()：关闭梯度计算，节省内存，加快速度。
  • 因为预测阶段不需要反向传播，所以不需要计算梯度。
  • pred = model(X)：用训练好的模型对训练数据做前向传播，得到预测值。
  • pred.round()：把概率值四舍五入到 0 或 1。
  • .flatten()：把形状 (4,1) 展平成一维。
  • .tolist()：转成 Python 列表，方便打印。
  • 期望输出接近 [0, 1, 1, 0]，说明模型学会了 XOR。
  • 打印原始的预测概率值，可以看到它们接近 0 或 1。

7. 关于手动梯度下降的补充

代码注释里提到，如果想更直观地看到梯度下降，可以把 optimizer.step() 替换为：

  • with torch.no_grad()：更新参数时不需要记录梯度。
  • for p in model.parameters()：遍历所有参数。
  • p -= lr * p.grad：手动执行 param = param - lr * grad。
  • 这等价于 optimizer.step()，但更底层，能看清梯度下降的本质。

8. 整体对应关系

步骤 代码 作用
前向传播 y_pred = model(X) 计算预测值
计算损失 loss = criterion(y_pred, y) 衡量预测与真实的差距
清空梯度 optimizer.zero_grad() 防止梯度累加
反向传播 loss.backward() 自动计算所有参数的梯度
梯度下降 optimizer.step() 用梯度更新参数
预测 with torch.no_grad(): pred = model(X) 关闭梯度，得到最终输出

这样，整个 PyTorch 训练流程就逐行解释完了。
