1.生成指定0-100随机数
#include <stdlib.h>
#include <time.h>

srand((unsigned)time(NULL)); // 程序启动时调用一次
int x = rand() % 100; // 0 ~ 99
int y = rand() % 100 + 1; // 1 ~ 100

提醒：rand() 是伪随机，% 有轻微分布偏差；要求高质量随机可用其他库
rand() % 100 可以生成 0~99，但 % 取模在部分情况下分布略有偏差；要求更均匀时可用：int x = (int)(100.0 * rand() / (RAND_MAX + 1.0)); // 0 ~ 99

补充：
（1）rand()伪随机是因为它的本质是一个算法生成的数字
（2）<stdlib.h>是rand（）的头文件
（3）rand的算法对一个叫种子的基准进行运算生成的
（4）种子默认为1，生成的随机数就永远是41，如果要求生成多个随机数那么就以18467，6334，26500.19169 …等等固定的数字
（5）srand(一ge运行的程序，调用一次即可）用来彻始化随机数的生成(种子)器
void srand （unsigned int seed);
通过srand 函数的参数 seed 来设置rand 函数成随机数时用的种子

（6）time
一般以时间作为种子
time t time (time_t*timer);
time返回的时间其实是当前时间与1970年1月1日0时0分0秒的差值，单位是秒，返回的类型为time-t(本质上就是32位或64位的整型)
time函数的参数timer如果是非NULL的指针的话函数会将这个返回的差值放在time指向的内存中，如果time是Null，就只返回这个时间的差值。 （time返回的这个时间差也被叫做:时间戳）

3.曾经的面试题，交换两数但不用第三个变量
方法一：a ^= b; b ^= a; a ^= b; // 交换两个整数，不用临时变量
原理：^支持交换律 例如0^a = a a^a = 0 3^5^3 = 5 3^3^5 = 5(^是计算机基础知识原码补码反码那里的二进制逻辑运算符)
优点：^不会进位，故而不会溢出

展开知识：
do { … } while (0) 是 C 语言里定义多语句宏的经典惯用法，核心目的是：宏内部的“多条语句”在语法上包装成“一条语句”，让它在 if/else/for/while 等控制流里表现正常。
因为宏只是文本替换，没有函数那样天然形成语句边界。

例如：
if (cond)
LOG(“ok”);
else
printf(“fail\n”);

展开为：
if (cond)
do { printf(“ok”); } while (0);
else
printf(“fail\n”);

其中：
do { … } while (0) 整体是一条语句；
while (0) 条件永远为假，所以循环体只执行一次，不会真的循环；
编译器通常会把这个无意义的循环优化掉，没有运行时开销；
{ … } 还提供了局部作用域，宏内部变量不会污染外部；
调用者仍然像普通语句一样写分号：LOG(“x”);，宏定义末尾通常不写分号。

所以 do-while(0) 主要解决的是：
多语句宏在 if/else 等场景下的语法错误、作用域污染和分号的问题。
对比一下：MAX 是表达式宏，它必须能出现在表达式里，所以不能用 do-while(0) 包，而是用括号保护：
#define MAX(a, b) ((a) > (b) ? (a) : (b))
而 LOG 是语句宏，所以用 do { … } while (0) 包装。
