零基础制作属于自己的Live2D形象：从下载到动起来的完整指南

本文从完全零基础的角度出发，带你完成第一个可动的Live2D模型。不需要任何建模经验，只需要一台电脑和一份想要动起来的插画。

开始之前，我们先理清整个流程的逻辑。Live2D的本质是让一张平面的插画，通过分层、网格变形和参数控制，产生三维运动感。它不是3D建模，也许像是2.5d

制作一个Live2D模型，大致需要经历这几个阶段：

绘画阶段：你需要一张线稿
准备阶段：安装Cubism Editor，准备一张分好图层的PSD插画。
建模阶段：导入PSD，为每个部件创建网格，用变形器搭建层级关系。
参数阶段：设置“角度X”“眼睛开闭”“嘴巴开合”等参数，并让部件随着参数动起来。
导出与使用：导出模型文件，配合追踪软件或SDK使用。

第一步：获取并安装 Live2D Cubism Editor
Live2D Cubism Editor 是制作Live2D模型的核心软件，官方提供免费版本可供使用。

下载
访问 Live2D 官方教程站点的下载入口即可获取最新版：https://docs.live2d.com/zh-CHS/cubism-editor-tutorials/top/

在官网下载页，你需要先阅读并同意软件使用授权协议，然后点击橙色的“下载最新版本”按钮。Cubism Editor 分为 Windows 版和 macOS 版，根据你的操作系统选择对应版本即可。

Windows 版下载后得到的是 Live2D_Cubism_Setup_X.X.XX.exe，macOS 版则是 .pkg 文件。

安装
Windows：双击安装包，依次点击“下一步”，接受许可协议，选择安装路径，点击“安装”等待完成即可。

macOS：双击 .pkg 文件，按照提示继续，输入系统密码授权安装，最后点击“关闭”完成。

启动与版本选择
首次启动 Cubism Editor 时，会弹出一个许可证选择对话框。这里有三个选项：

PRO版：需要输入许可证密钥激活，功能无限制。
Trial版：免费试用42天的PRO版全部功能，从首次启动之日起算。
FREE版：永久免费，但有功能限制。

对于零基础的新手，建议直接选择“开始免费试用PRO版” 。42天的试用期足够你完成第一个模型的学习。试用期结束后，软件会自动转为FREE版，你仍然可以打开之前用PRO版保存的文件，但保存时需要将数据裁剪到FREE版的限制范围内。

FREE版的核心限制包括：纹理文件最多1张（最大2048px）、ArtMesh最多100个、参数最多30个、变形器最多50个、图片分割数最大9×9。对于简单的小模型，这些限制通常够用；但如果你的插画图层很多、想做精细的头部运动，FREE版可能会在中途卡住。

安装完成后，你会在电脑上看到两个程序：Cubism Editor（编辑器）和 Cubism Viewer（查看器）。制作模型主要用 Editor。

官方教程站点提供了完整的初学者教程和基础教程（共6课），建议在开始之前先浏览一遍视频，对流程有个整体印象。

第二步：准备你的插画素材
Live2D 不能直接处理一张扁平的 JPG 或 PNG。它需要的是分层 PSD 文件，每个需要独立运动的部件都必须是单独的图层。

画线稿可以使用优动漫(乃树坂串绪老师推荐的，但是没有免费版，小贵)
拆分可以用https://www.photopea.com/

草稿 → 线稿 → 上色（完整画完） → 补全隐藏部分 → 拆分图层 → 整理命名 → 导出 PSD

先明确一个核心原则：画的时候就要想着“拆”
大部分新手犯的错误是：先画完一张完整的立绘，然后再痛苦地手动拆分。有博主分享过真实经历——立绘绘制花了约 7 小时，拆分拆了 14 小时。

正确的做法是：在绘制阶段就按 Live2D 的拆分逻辑来画。 每一个将来需要独立运动的部件，从线稿阶段就单独建图层。

第 1 步：确定角色设计和姿势
画正面对称的角色。正面的可动性最高，也最容易拆分。不要一开始就画大侧身或者复杂透视，那会给拆分和建模都带来不必要的麻烦。
如果你的目标只是先走通流程，画一个 Q 版角色是很好的选择。Q 版比例简单，图层数量少，官方入门教程以及大多数B站教程也是从 Q 版开始的。

第 2 步：草稿与线稿——按部件分层描线（描线之前要注意部件的拆分）
从草稿开始，就需要养成“分层”的习惯。不要把所有东西画在同一层上。
推荐的绘制顺序是：先画整体草稿作为参考，然后新建图层，逐个部件描线。
按照 Live2D 的拆分标准，一个角色的线稿至少需要覆盖以下部件：

头发部分
前发（刘海）：如果刘海分成左、中、右几片，每片单独一层
侧发：左右分开
后发：一整层，但必须补全被头部遮挡的部分（头壳顶部的头发）
呆毛（如果角色有）：单独一层

脸部部分
脸部轮廓：描线时不要只描可见的边缘，要把被头发遮住的发际线、额头也画出来
眉毛：左右分开
眼睛：这是最需要细分的区域
上睫毛（左右分开）
下睫毛（左右分开）
眼白（左右分开，且必须补全被瞳孔遮挡的部分）
眼珠/瞳孔（左右分开）
高光（左右分开，如果高光需要独立运动）

鼻子

嘴巴：上唇、下唇、嘴巴内部（张嘴时能看到的区域）

耳朵：左右分开，补全被头发遮住的部分

身体部分

脖子：画得比实际可见的长一些，这样头部转动时不会被“切掉”

躯干/衣服

手臂：按上臂、前臂、手来分

饰品：如果想让丝带、耳环飘动，单独分层

线稿的线条要有一定粗细和清晰度，但不需要过度风格化，因为在 Live2D 中线条会随着变形拉伸，太夸张的笔触在运动时可能显得奇怪。

第 3 步：上色——每个部件独立铺色
上色阶段继续沿用图层分离的逻辑。不要把所有颜色合并到一个图层再拆分。（先上底色，在以拆分部件为准着色）

推荐的上色流程是二次元插画常用的方式
铺固有色：为每个部件铺上基础颜色，颜色选择偏灰、偏左上的区域（不要用纯黑阴影或纯白高光）
画二分阴影：设定一个光源方向，用正片叠底图层画暗部。形状要有“整”有“碎”，大块面和小细节结合
加灰部过渡：用柔和笔刷让明暗过渡自然
卡闭塞：在光源照不到的角落加深，增强体积感
高光和补色：提亮关键区域，增加画面层次

关键要求：每个部件的颜色和线条需要在同一图层或同一组内，方便后续合并。Live2D 的“载入用 PSD”要求一个部件对应一个图层。

第 4 步：补全“隐藏部分”——这一步最容易被忽略，也最重要
Live2D 的官方文档反复强调这一点：划分的时候请勿忘记加上原图中隐藏的部分。如果没有额外的绘图，当部分移动时，它看起来将不连贯。

具体来说：

脸部轮廓：头发遮住的额头、鬓角遮住的侧脸，都要画出来，填充肤色。

眼白：瞳孔遮住的那部分眼白必须补全，否则眼球移动时会露出空洞。

脖子：画到嘴巴附近，确保头部倾斜时脖子仍然连贯。

嘴巴内部：张嘴时能看到的口腔内部、牙齿，在闭嘴状态下虽然看不见，但必须画出来。嘴巴内部的绘制尺寸要比可见区域大一号，防止变形时露出边缘。

后发：头顶被前发遮住的头发区域要补全，发旋的位置可以画出来。头发的内面（翻起来看到的那一面）建议用暗色。

第 5 步：整理图层命名与结构
图层命名混乱是后期调试的难点。在导出 PSD 之前，必须做好整理。
调整某一层的时候，可以把该图层透明度降到 50%，可以透视看到底下底图对齐，对齐完透明度改回 100%

命名规则：
用中文或英文描述性名称，不要用“图层 57”“副本 3”（考虑兼容性）
左右部件明确标注：左眉 / 右眉，左眼白 / 右眼白
如果有多层结构（比如眼睛包含眼白、瞳孔、高光），用一个组来管理：组名 左眼，内部图层 眼白、瞳孔、高光

图层顺序：按照从前到后的遮挡关系排列。但 Live2D 导入后会根据 PSD 的图层结构生成部件层级，所以 PSD 中的顺序要符合视觉逻辑。

第 6 步：创建两个 PSD 文件（也就是在图层合并完成后选择另存为.pds文件，保留涂层结构

这是 Live2D 官方推荐的工作方式：

文件 A：素材拆分用 PSD（工作文件）
保留所有图层、图层蒙版、剪贴蒙版、组结构。这个文件用于后续修改和调整。

命名建议：角色名_素材拆分.psd

文件 B：载入用 PSD（导入 Cubism Editor 用）
将素材拆分用 PSD 中的每个部件组合并为单个图层。即：每个部件（组）对应一个图层，合并线稿、颜色、阴影等所有内容。

命名建议：角色名_载入.psd

合并时的注意事项：

图层属性：PSD 中的混合模式如果设置为“正常”以外的值（如正片叠底、滤色等），导入 Cubism Editor 时会尝试匹配其色彩混合属性。如果 Editor 中没有对应模式，会自动改为“正常”。建议在载入用 PSD 中尽量使用“正常”混合模式，导入后再在 Editor 中设置。

不透明度 vs 填充：PSD 中的“不透明度”会被 Editor 保留，“填充”则不会。如果需要做腮红等半透明效果，用“不透明度”而不是“填充”来调整。

不使用图层蒙版：如果素材拆分用 PSD 中还有图层蒙版，在合并前先“应用图层蒙版”。

色彩模式：必须是 RGB，色彩配置文件设为 sRGB。

检查路径信息：如果使用 Photoshop CC 2019 或更高版本，PSD 中可能包含路径信息，导入可能失败。在合并前删除所有路径。

清理垃圾：删掉画布上任何忘记擦除的杂点或透明区域，它们会被 Editor 当作素材处理，导致自动网格生成出错。

第 7 步：导出 PSD 并导入 Live2D
将“载入用 PSD”保存好之后，就可以回到原文的第四步——打开 Cubism Editor，将 PSD 拖入工作区，开始创建 ArtMesh 和变形器了。
1.将pds拖入即可，读完进度条即可显示完毕
2.乃树坂串绪老师书中提供教程
菜单栏——文件——创建——模型 即可创建名为“Untitled Model”的新模型文件区域中，打开“模型设定”对话框。选择“Untitled Model(模型)”，单击“OK”后会弹出“再次导入的设定”对话框。

注意：如果使用.psd文件创建新模型且在”模型设定”对话框中选择”使用PSD文件创建新模型”则不会弹出“再次导入的设定”对话框，直接完成导入。

在”再次导入的设定”对话框中 再次导入的设定
选择”<将所有图层添加为新的图形网格>”，单击”OK”，即可导入.psd文件。

注意：如果导入的.psd文件的尺寸大于新创建的模型文件的画布尺寸，则可能出现模型超出画布的情况。如 果需要将.psd文件导入固定尺寸画布，也可以使用这种方式，但推荐 直接拖入

注意：在查看区域中用鼠标拖动部件，确认部件是否为独立且分开的状态,如果是，则.psd文件导入完成。

如果你在绘制阶段已经按照上述方式拆分了图层，导入后的部件面板会直接呈现出清晰的结构，省去大量后期整理的时间。

补充建议：如果你完全不会画画，或者想先专注学习 Live2D 的操作，可以下载 Live2D 官方的 SD 模板来练习建模，跳过绘制阶段直接体验完整流程。但如果你希望拥有一个真正属于自己的形象，从线稿到 PSD 的这一步是绕不开的，而且画的时候多想着“这个部件会不会单独动”，后面的建模会顺利很多。

图层拆分的原则
你需要把角色拆解成足够细致的部件。以一张半身像为例，通常至少需要分离出以下部分：

头部相关：前发、后发、脸部轮廓、眉毛（左右）、上睫毛（左右）、下睫毛（左右）、眼白（左右）、瞳孔（左右）、高光（左右）、嘴巴、鼻子、耳朵（左右）。

身体相关：脖子、肩膀、衣服主体、手臂、手。

关键注意事项
画的时候要多画一些“藏起来”的部分。这是新手最容易忽略的。当你转动头部时，原本被头发遮住的皮肤会露出来；闭眼时，被睫毛挡住的眼皮需要存在；张嘴时，嘴巴内部和牙齿需要能看到。所以在绘制素材时，所有可能露出的区域都要画全，宁可多画不能少画。

图层命名要清晰。不要把图层叫“图层57”或“副本3”。用“左眉”“右眼白”“前发”这样的命名。Live2D 在导入 PSD 时会把图层结构直接映射成部件列表，命名混乱会让你在后期调试时非常痛苦。

合并同类图层。比如眼白、瞳孔、高光如果不需要独立运动，可以合并为一层“左眼”；但如果瞳孔需要单独移动（比如视线追踪），就必须保持分离。

导出格式：PSD，色彩模式 RGB，色彩配置文件 sRGB。图层混合模式尽量使用“正常”，不透明度100%。Photoshop 的剪贴蒙版不会直接导入到 Live2D，需要在 Editor 中重新设置。

如果你完全不会画画，或者想先熟悉流程再画自己的素材，官方提供了一个模板功能，可以直接下载预设的 SD 角色模板来练习：https://docs.live2d.com/cubism-editor-tutorials/template/

第三步：导入 PSD 并创建 ArtMesh
打开 Cubism Editor，选择“创建新项目”，然后将你的 PSD 文件直接拖拽到 Editor 的“Model”工作区中。

导入后，你会看到左侧的部件列表和右侧的模型预览。PSD 的图层结构会原封不动地出现在部件列表中。

什么是 ArtMesh
Editor 会自动为每个图层分配一个ArtMesh（艺术网格）。ArtMesh 是一个由顶点和线构成的多边形网格，覆盖在图像上方。当你移动 ArtMesh 的顶点时，底下的图像就会跟着变形。

自动生成的 ArtMesh 通常比较粗糙，对于大面积的头发、衣服等简单形状够用，但对于眼睛、嘴巴等需要精细变形的部位，你需要手动编辑网格。

哪些部位需要手动编辑
以下部位建议手动重画 ArtMesh 以获得更好的变形效果：

眼部轮廓（睫毛） ：需要沿着睫毛的弧度布置顶点，让睫毛在闭合时能自然弯曲而不是生硬折叠。
嘴巴：上下唇的顶点需要加密，嘴型变化（啊、咦、呜）才能流畅过渡。
鼻子：虽然鼻子运动幅度小，但顶点位置不当会导致变形时出现尖锐的拉扯。
其他需要精细变形的地方：比如衣服的褶皱、飘带等。

编辑网格时，可以使用工具栏的“镜像编辑”功能，让左右对称的部件（如左右眼）的网格修改保持同步。

常见问题：变形时出现“撕裂”
如果变形后图像某个部分被拉得很尖锐或出现空洞，通常是 ArtMesh 的顶点不够或者三角形太细长。避免使用过于狭长的三角形，尽量让网格的三角形接近等边形状。在运动剧烈的区域（如嘴角、眼皮）增加顶点密度。

第四步：用变形器和参数搭建运动系统
这是 Live2D 建模的核心逻辑，也是新手最容易卡住的地方。理解了变形器的层级关系，后面的操作就顺了。

变形器是什么
变形器本身不直接对应图像，它是一个容器。你把 ArtMesh 放进变形器里，变形器动，里面的 ArtMesh 就跟着动。

有两种变形器：
弯曲变形器（Warp Deformer） ：可以自由拖拽控制点，让内部物体产生弯曲、拉伸、压缩。适合头发、身体等需要柔和变形的部位。
旋转变形器（Rotation Deformer） ：只能旋转和缩放，适合眼球、头部整体转向等。

层级关系：从大到小
正确的层级结构是：大的变形器包含小的变形器，小的变形器包含 ArtMesh。

举个例子，一个典型的头部结构可能是这样的：
头部旋转（Rotation Deformer）
├── 脸部（Warp Deformer）
│ ├── 左眼组（Warp）
│ │ ├── 左眼白（ArtMesh）
│ │ ├── 左瞳孔（ArtMesh）
│ │ └── 左睫毛（ArtMesh）
│ ├── 右眼组（Warp）
│ ├── 嘴巴（Warp）
│ └── 鼻子（ArtMesh）
├── 前发（Warp）
└── 后发（Warp）
当“头部旋转”变形器转动时，整个头部跟着动。当“左眼组”单独调整时，只有左眼动。这种嵌套结构让你可以从整体到局部逐级控制。

注意：变形器内部的 ArtMesh 不要超出变形器的范围，否则变形时可能会出现意外的拉伸。

创建参数
参数是驱动运动的“控制杆”。在 Editor 的参数面板中，你可以创建各种参数，每个参数有一个 0 到 1（或 -1 到 1）的取值区间。

常用的基础参数包括：
ParamAngleX：头部左右转动（-30 到 30）
ParamAngleY：头部上下转动（-30 到 30）
ParamAngleZ：头部倾斜（-30 到 30）
ParamEyeLOpen / ParamEyeROpen：眼睛开闭（0 到 1）
ParamEyeBallX / ParamEyeBallY：眼球移动（-1 到 1）
ParamMouthOpenY：嘴巴张合（0 到 1）
ParamBodyAngleX：身体左右倾斜（-10 到 10）

选中一个变形器，切换到某个参数值（比如 ParamAngleX = 30），然后拖拽变形器让头部向右转，这个姿态就会被记录在参数上。回到 0，再设置向左转的姿态。Live2D 会在关键姿态之间自动插值，产生平滑的运动。

给主要部件设置参数的基本思路
头部XY：选中头部旋转变形器，在 ParamAngleX 的 -30、0、30 三个值上分别设置左转、正中、右转的姿态。然后对 ParamAngleY 做同样的操作。

眼睛开闭：选中包含睫毛和眼皮的变形器，在 ParamEyeOpen 的 0 和 1 上设置闭眼和睁眼的姿态。

嘴巴：选中嘴巴变形器，在 ParamMouthOpenY 的 0 和 1 上设置闭嘴和张嘴。

眼球：选中瞳孔的 ArtMesh，在 ParamEyeBallX 和 ParamEyeBallY 上设置瞳孔的移动范围。

具体操作时，官方的基础教程（共6次课程）有详细的视频演示，建议跟着做一遍。

第五步：添加物理效果和动画
当基本参数都设置好后，你的模型已经可以手动拖拽参数来“摆姿势”了。但它还不能自己动。

物理模拟
Live2D 有一个物理模拟系统，可以让头发、饰品等部件在头部转动时产生自然的摆动。在 Editor 中打开“物理”面板，你可以为头发、飘带等部件设置摆锤式的物理效果，让它们随着头部运动产生延迟和回弹。

动画
如果你想让模型做出一套完整的动作（比如一个打招呼的循环），需要进入“Animation”模式，在时间轴上为参数设置关键帧，创建 Motion 文件。这部分的内容相对进阶，建议在完成第一个可动模型后再深入学习。

第六步：导出和使用
导出模型文件
在 Editor 中完成建模后，通过“文件 → 导出”可以输出以下文件：

.moc3：模型的核心数据文件，包含网格、变形器和参数信息。
纹理图片：模型的贴图文件（通常是 PNG）。
.model3.json：模型的配置文件，描述纹理路径、物理设置、动作文件等。

这三个文件组合在一起，才能被 SDK 或追踪软件正确加载。

让它动起来
导出后的模型可以通过多种方式使用：

nizima LIVE：Live2D 官方面部追踪软件，可以用摄像头捕捉你的表情和头部运动，实时驱动模型。需要注册 nizima 账号，免费版有功能限制（包括 logo 显示）。下载地址：https://docs.live2d.com/nizimalive/en/tutorials/introduction/

Cubism SDK：如果你有开发能力，可以用 SDK 将模型嵌入到自己的应用或网页中。Web 版 SDK 的下载页面在这里：https://www.live2d.com/en/sdk/download/web/

视频制作：导出模型后，也可以在动画软件中录制动作，用于视频内容制作。

刚开始做模型简陋很正常，多花点时间

善用官方教程。Live2D 的官方文档和视频教程质量很高，而且是中文的。遇到具体问题时，直接在教程站搜索关键词，通常能找到对应的说明：https://docs.live2d.com/zh-CHS/cubism-editor-tutorials/top/

42天试用期是足够的。如果你每天花1-2小时，两周左右就能做出一个简单但可用的模型。试用期结束后，你仍然可以用 FREE 版继续调整已有的模型，或者等到真正需要时再购买 PRO。

从“模板”开始也是好选择。如果你对画图不熟练，或者想先专注学习 Live2D 的操作而不是画图，官方的 SD 模板功能可以让你跳过素材准备阶段，直接体验完整的建模流程。

以上就是零基础制作 Live2D 形象的完整流程。从安装软件到导出可用的模型文件，整个路径虽然不短，但每一步都有官方的中文文档和视频教程可以参照。祝你做出属于自己的第一个 Live2D 形象。
