Blender 快捷键完全指南：从入门到精通的效率手册

一、全局快捷键

全局快捷键在所有编辑器与模式下均有效，是操作 Blender 的基础层。

快捷键 功能
Ctrl + O 打开文件
Ctrl + S 保存文件
Ctrl + N 新建文件
Ctrl + Z 撤销
Shift + Ctrl + Z 重做
Ctrl + Q 退出
F1 帮助（上下文敏感）
F2 重命名活动项目
F3 菜单搜索
F9 调整上一次操作
F11 显示渲染窗口
F12 渲染当前帧
Q 快速访问（收藏夹）
Ctrl + Spacebar 切换区域最大化
Ctrl + PageUp / PageDown 切换上一个/下一个工作区

F9 是 Blender 中极具价值的快捷键，在完成任意操作后按下，可在视口左下角弹出参数调整面板，实时修改该操作的具体参数，无需撤销重做。F3 菜单搜索则允许用户通过关键词检索任意功能，是学习和探索 Blender 功能的高效入口。

二、视图导航

视图导航是三维操作中频率最高的动作。Blender 默认使用数字小键盘进行视角控制，笔记本电脑用户可在偏好设置中开启“模拟数字小键盘”以获得等效功能。

快捷键 功能
鼠标中键拖动 旋转视图
Shift + 鼠标中键 平移视图
鼠标滚轮 缩放视图
小键盘 1 前视图
Ctrl + 小键盘 1 后视图
小键盘 3 右视图
Ctrl + 小键盘 3 左视图
小键盘 7 顶视图
Ctrl + 小键盘 7 底视图
小键盘 0 摄像机视图
小键盘 5 切换正交/透视投影
小键盘 . 聚焦选中对象
Home 显示场景中所有对象
~ 打开视图导航饼菜单

在物体模式下，通过 小键盘 . 聚焦选中对象是最常用的导航操作之一。~ 键唤出的饼菜单集成了视图切换、摄像机控制和透视模式切换等功能，适合不便使用数字小键盘的场景。

三、物体模式

物体模式是 Blender 的默认工作模式，用于对场景中的对象进行整体操作。

3.1 变换操作

快捷键 功能
G 移动（Grab）
R 旋转（Rotate）
S 缩放（Scale）
G / R / S 后按 X / Y / Z 沿指定轴向操作
G / R / S 后按 Shift + X / Y / Z 排除指定轴向
Shift + 鼠标中键拖动 精确控制变换
Alt + G 清除位置
Alt + R 清除旋转
Alt + S 清除缩放

变换操作的核心逻辑是：按下 G、R 或 S 进入对应模式后，移动鼠标即可实时预览变换效果，按 X、Y、Z 锁定轴向，单击左键确认或单击右键取消。在变换过程中按住 Ctrl 可启用增量吸附，按住 Shift 可进行精细微调。

3.2 选择与编辑

快捷键 功能
A 全选
Alt + A / 双击 A 取消全选
Ctrl + I 反选
B 框选
Shift + 鼠标左键 加选
Shift + D 复制对象
Alt + D 关联复制
Ctrl + J 合并选中对象
X 删除（需确认）
Delete 删除（无需确认）
H 隐藏选中
Shift + H 隐藏未选中
Alt + H 显示所有隐藏对象
M 移动至集合
Shift + A 添加对象
Ctrl + A 应用变换（位置/旋转/缩放）

Shift + D 与 Alt + D 的区别在于：前者创建独立副本，修改副本不影响原对象；后者创建关联副本，修改任意一个实例的数据会同步影响所有实例。Ctrl + J 将多个选中对象合并为一个对象，合并后对象的原点位于活动对象的原点位置。

四、编辑模式

按 Tab 键在物体模式与编辑模式之间切换。编辑模式用于对网格的顶点、边、面进行精细编辑。

4.1 选择模式切换

快捷键 功能
1 顶点选择模式
2 边选择模式
3 面选择模式
Shift + 1 / 2 / 3 叠加选择模式
Ctrl + Tab 模式切换饼菜单

1、2、3 分别对应顶点、边、面三种选择模式。按住 Shift 可同时激活多种模式，实现跨层级的混合选择。Ctrl + Tab 唤出模式切换饼菜单，可快速跳转至编辑模式、雕刻模式、权重绘制模式等。

4.2 网格编辑操作

快捷键 功能
E 挤出（Extrude）
Ctrl + R 环切（Loop Cut）
K 切割工具（Knife）
F 创建边/面
Ctrl + B 倒角（Bevel）
Ctrl + Shift + B 顶点倒角
Alt + M 合并顶点
P 分离选中部分
M 合并顶点
U UV 展开菜单
Shift + N 重新计算法线
Alt + 鼠标左键 选择循环边

Ctrl + R 环切是网格建模中使用频率极高的操作：按下后在网格上预览切割线位置，滚动滚轮可增加切割数量，单击确认位置后可拖动滑块调整偏移。Alt + 鼠标左键 点击边可选中整条循环边，是对环形结构进行整体编辑的关键操作。

4.3 选择操作

快捷键 功能
B 框选
C 刷选
Ctrl + 数字键盘 + 扩展选择
Ctrl + 数字键盘 - 缩减选择
L 选择相连元素
Shift + L 扩展选择相连元素
Ctrl + L 选择相连的网格岛
Alt + 点击 循环边/面选择

五、动画快捷键

快捷键 功能
I 插入关键帧
Alt + I 删除当前帧关键帧
Shift + Alt + I 删除所有关键帧
Spacebar 播放/暂停动画
← / → 前后移动一帧
Shift + ← / Shift + → 跳至首帧/末帧
↑ / ↓ 前后移动十帧

插入关键帧的标准操作是：将鼠标悬停在需要动画的属性上，按 I 键调出关键帧菜单，选择需要记录的属性通道。Alt + I 用于删除当前帧上的关键帧，配合悬停在属性值上使用可精确删除指定通道的关键帧。

六、UV 编辑器快捷键

UV 编辑器与 3D 视口共享部分快捷键（如 A、Alt + A、Ctrl + I 等），同时具有专属操作。

快捷键 功能
U 展开 UV 菜单
E 展开（Unwrap）
Ctrl + E 边菜单（标记缝合边等）
L 选择相连 UV 岛
Ctrl + L 选择相连 UV
G / R / S 移动/旋转/缩放 UV
P 固定选中 UV

七、雕刻模式快捷键

雕刻模式的核心操作围绕笔刷控制展开。

快捷键 功能
F 调整笔刷大小
Shift + F 调整笔刷强度
Ctrl + F 调整笔刷角度
Shift + 鼠标左键 临时平滑笔刷
Ctrl + 鼠标左键 反向雕刻（凹陷）
D 切换笔刷大小调整模式
M 创建遮罩
Ctrl + M 反转遮罩
Alt + M 清除遮罩
H 隐藏未遮罩部分
Shift + H 隐藏活动面组
Alt + H 显示全部
Shift + R 调整体素大小 / 重构网格

雕刻过程中按住 Shift 可临时切换至平滑笔刷，松开后恢复原笔刷，这一设计避免了频繁切换工具的打断感。F 键调整笔刷大小时，左右移动鼠标即可实时改变半径，单击确认。Shift + R 用于调整体素重构网格的分辨率，在高精度雕刻中控制网格密度。

八、节点编辑器快捷键

节点编辑器（着色器节点、几何节点、合成节点）在操作逻辑上继承了 Blender 编辑器通用快捷键，同时具有节点特有的操作。

快捷键 功能
Shift + A 添加节点
Shift + D 复制节点
G 移动节点
Ctrl + Shift + 鼠标左键 快速预览节点
Ctrl + T 添加纹理坐标与映射节点
Ctrl + Shift + T 从文件添加贴图
Ctrl + J 自动连接节点
M 静音节点
Ctrl + G 创建节点组
Tab 进入/退出节点组
小键盘 . 聚焦选中节点

Ctrl + Shift + 鼠标左键 在节点编辑器中用于快速预览节点输出效果，无需手动连接查看器节点，是材质调试中的高效操作。Ctrl + J 可自动连接两个选中节点的输出与输入，简化了手动拖拽连线的操作。

九、Blender 4.x 版本键位变更

Blender 4.0 对键位映射进行了系统性调整，旨在提升一致性与减少冲突。以下为主要变更内容。

新增与调整：

  • 偏好设置窗口可通过 Ctrl + 逗号 打开
  • 标记可通过双击左键重命名
  • Alt + 鼠标左键 在雕刻与绘制模式中用于选择（此前无此绑定）
  • Shift + Alt + 鼠标左键 用于扩展/切换选择

移除与重新分配：

  • 姿态模式下 1 至 0 切换场景集合的快捷键被移除
  • 雕刻模式与蜡笔模式中部分笔刷快捷键被移除或重新分配
  • 顶点绘制模式下 Shift + K 改为 Ctrl + X

帧操作变更：

  • Blender 4.5 及以上版本中，帧重命名快捷键简化为 F，按下后直接进入标签编辑状态

上述变更意味着从 Blender 3.x 迁移至 4.x 的用户需要重新适应部分键位。建议在偏好设置的键位映射编辑器中查看完整变更清单，或通过 F3 菜单搜索功能定位具体操作。
