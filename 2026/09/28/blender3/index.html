Blender 原点完全解析：作用、快捷键与工作流实践

前言

在 Blender 中，原点（Object Origin）是每个物体局部坐标系的核心参照点，在视口中通常显示为橙色小点。原点并非几何体中心，也不等同于世界原点或 3D 游标，而是物体自身位置、旋转与缩放属性的承载点。理解原点的作用机制，直接关系到变换操作、修改器行为、动画旋转、父子关系、几何节点坐标以及吸附对齐等核心工作流。本文系统梳理 Blender 原点的定义、作用、设置方法、典型应用与快捷键，并区分其与世界原点、3D 游标、轴心点等相关概念。

原点就是计算机认为的你的模型的位置，所有与原点相关的操作都基于这个概念

一、原点的定义与显示

物体原点是物体局部坐标系的原点，也是该物体位置属性的数值表示点。在 3D 视口中，选中物体后可见橙色小点或橙色圆圈，即为物体原点。原点同时具有位置与旋转属性，缩放属性通常不直接体现为可视标记，但会影响物体局部坐标轴。

原点的位置与旋转可在 3D 视口侧栏中查看和编辑。按下 N 键展开侧栏，在“物品”选项卡的“变换”面板中，位置、旋转、缩放三组数值均以原点为基准。修改位置数值会移动整个物体，包括几何体；若启用“仅影响原点”模式，则仅移动原点而不移动几何体。

原点与几何体的关系是：几何体顶点坐标相对于物体原点存储。原点的位置变化会改变物体变换值，但不会自动改变几何体在局部空间中的坐标，除非执行特定操作。

二、原点与相关概念的区别

Blender 中存在多个容易混淆的参照概念，需明确区分。

概念 属性 作用 相关快捷键
物体原点 每个物体独立的局部坐标原点 物体变换、修改器、约束、动画、父子关系的参照 N 查看与编辑；Ctrl + Shift + Alt + C 旧版设置原点菜单
世界原点 全局坐标系原点，坐标为 (0, 0, 0) 全局空间参照 Shift + C 将游标复位至世界原点；Ctrl + A 应用位置可将物体原点重置到世界原点
3D 游标 场景级参照点，具有位置与旋转 放置新物体、设置原点、吸附目标、变换轴心 Shift + 鼠标右键 放置；Shift + S 吸附菜单；Shift + C 复位
轴心点 变换操作围绕的中心，非几何实体 控制旋转与缩放的围绕中心 句号键（.） 打开轴心点饼菜单；Ctrl + 句号键（.） 切换仅影响原点

轴心点与原点关系密切。默认轴心点为“中位点”，选中单个物体时与物体原点重合；选中多个物体时，中位点为各物体原点的平均值。若在轴心点菜单中选择“各自原点”，则每个物体围绕自身原点独立变换。

三、原点的核心作用

3.1 定义物体局部坐标系

原点是物体局部坐标系的零点。物体局部坐标轴的方向由原点的旋转属性决定。执行变换时，按 G、R、S 后连续按两次轴向键，可切换至局部轴向操作。例如，按 G 后按 X 两次，将沿物体局部 X 轴移动。局部坐标系的方向直接影响建模、装配与动画的轴向判断。

3.2 作为变换的默认参照

在物体模式下，单个物体的旋转与缩放默认围绕其原点进行。若需围绕其他点变换，可通过 句号键（.） 切换轴心点至 3D 游标、边界框中心、质心点或活动元素。若需每个选中物体围绕自身原点变换，可在轴心点菜单中选择“各自原点”。

“仅影响原点”模式通过 Ctrl + 句号键（.） 切换。启用后，G、R、S 仅调整原点位置与旋转，几何体保持不动。该模式常用于在不改变物体视觉位置的前提下修正原点。

3.3 决定修改器的参照基准

多个修改器以物体原点或局部坐标轴为计算基准。镜像修改器默认围绕物体原点或指定镜像对象进行镜像，原点位置决定镜像平面的位置。阵列修改器的相对偏移基于物体局部坐标。简易形变、弯曲、扭曲等修改器同样受原点位置与旋转影响。原点的错误设置会导致修改器结果偏离预期。

3.4 影响约束与动画

约束中的“复制旋转”“限制距离”“子级 Of”等均可能以物体原点为参照。旋转动画围绕原点生成，若原点位于门轴、关节或轮心，旋转动画即可直接获得自然效果。若原点偏离旋转轴，动画将产生不必要的位移。

3.5 决定父子关系中的相对位置

父子关系中，子物体的位置与旋转相对于父物体原点计算。父物体原点移动时，子物体随之移动；父物体原点旋转时，子物体围绕父物体原点旋转。因此，父物体原点的位置决定了子物体的运动轨迹。

3.6 控制几何节点与纹理坐标

几何节点中，Position 输入返回的是相对于物体原点的局部坐标。着色器中的“物体”纹理坐标同样基于物体原点。原点位置与旋转会改变程序纹理、生成坐标与几何节点效果的空间分布。

3.7 作为吸附与对齐目标

吸附操作可将选中元素移动至游标，也可将游标移动至选中元素。通过 Shift + S 打开吸附菜单，常用选项包括：

吸附操作 功能
游标到选中项 将游标移动到选中元素的中心或原点位置
选中项到游标 将选中物体移动至游标位置，通常使其原点与游标对齐
游标到世界原点 将游标复位至世界原点
游标到栅格点 将游标吸附至最近栅格交点
选中项到游标（偏移） 保持选中物体相对位置，整体中心对齐至游标

在物体模式中，吸附目标可设置为“原点”，从而将其他元素吸附至物体原点。

3.8 影响复制与合并

Shift + D 复制物体时，副本原点与原物体原点位置相同。Alt + D 关联复制同样保留原点。Ctrl + J 合并多个物体时，合并后物体的原点取活动对象的原点，其他几何体坐标转换至该原点坐标系下。

四、原点的设置与移动

4.1 通过菜单设置原点

在物体模式下选中物体，可通过物体菜单或右键上下文菜单进入“设置原点”子菜单。Blender 2.8 之前，Ctrl + Shift + Alt + C 可打开设置原点菜单；Blender 2.8 及之后，该功能主要位于菜单中，默认键位映射未必保留该组合键，可通过 F3 搜索 Set Origin 调用。

设置原点菜单常见选项：

选项 作用
原点到几何中心 将原点移动至网格几何中心
原点到质心（体积） 将原点移动至体积质心
原点到质心（表面） 将原点移动至表面质心
原点到 3D 游标 将原点移动至当前 3D 游标位置
几何到原点 保持原点位置不变，将几何体移动至原点

4.2 通过游标精确设置原点

将原点设置到特定顶点、边或面是常见需求。操作流程为：

  1. 按 Tab 进入编辑模式。
  2. 选择目标顶点、边或面。
  3. 按 Shift + S，选择“游标到选中项”。
  4. 按 Tab 返回物体模式。
  5. 通过“设置原点 → 原点到 3D 游标”将原点移动至该位置。

该流程适用于门轴、关节、轮心、脚底等需要精确原点的场景。

4.3 使用“仅影响原点”模式

按 Ctrl + 句号键（.） 切换“仅影响原点”。启用后，使用 G、R、S 可单独调整原点位置与旋转，几何体保持不动。该模式适合在不改变物体视觉位置的前提下修正原点，例如将原点从几何中心移动至物体底部。

4.4 通过应用变换重置原点

Ctrl + A 打开应用变换菜单。选择“位置”后，物体位置归零，原点移动至世界原点，几何体在世界空间中的位置保持不变。选择“旋转”或“缩放”可重置相应变换。应用全部变换后，物体原点位于世界原点，局部坐标轴与世界坐标轴对齐。

Alt + G 清除位置会将物体位置归零，物体连同几何体一起回到世界原点，不属于仅重置原点的操作。

4.5 精确数值编辑

按 N 展开侧栏，在“物品 → 变换”中可直接输入位置与旋转数值，精确控制原点坐标与朝向。若启用“仅影响原点”，数值修改仅作用于原点；若未启用，修改位置会移动整个物体。

五、典型工作流

5.1 门轴与机械关节

在编辑模式下选择门轴位置的边或顶点，按 Shift + S 将游标吸附至该处，返回物体模式后将原点设置到 3D 游标。此后按 R 旋转门板，旋转轴即为门轴，无需额外约束。

5.2 车轮旋转

将车轮原点设置到轮心位置。旋转动画围绕原点生成，车轮可正确自转。若原点位于车轮边缘，旋转将产生公转偏移。

5.3 脚底与地面放置

将角色或道具原点设置到脚底或底部中心。移动物体时，原点直接对应地面接触点，便于对齐地面与摆放场景。

5.4 镜像修改器

镜像修改器默认以物体原点为镜像中心。将原点放置在模型对称面上，镜像结果沿该平面对称。若原点偏移，镜像平面随之偏移。

5.5 阵列修改器

阵列修改器的相对偏移基于物体局部坐标。原点位置与旋转决定阵列方向与间距。通过调整原点旋转，可改变阵列的局部轴向。

5.6 导入模型修正

外部导入模型常出现原点远离几何体的情况。可通过“原点到几何中心”或“原点到 3D 游标”修正。若需将模型放置于世界原点，可先按 Shift + C 将游标复位至世界原点，再将原点设置到 3D 游标。

5.7 对齐与吸附

选中参考物体，按 Shift + S 选择“游标到选中项”，将游标置于参考物体原点；再选中目标物体，按 Shift + S 选择“选中项到游标”，目标物体原点即对齐至参考物体原点。

六、快捷键汇总

快捷键 功能
Tab 切换物体模式与编辑模式
N 展开侧栏，查看与编辑原点位置、旋转
Shift + S 打开吸附菜单，含游标与选中项互相对齐选项
Shift + C 将游标复位至世界原点并显示全部场景
Ctrl + Shift + Alt + C 旧版或部分键位映射中打开设置原点菜单
F3 搜索 Set Origin 相关命令
Ctrl + A 应用变换菜单，可将原点重置到世界原点
Alt + G 清除位置，物体回到世界原点，几何体随动
句号键（.） 打开轴心点饼菜单，选择各自原点、3D 游标等
Ctrl + 句号键（.） 切换“仅影响原点”模式
G / R / S 变换物体；在仅影响原点模式下调整原点
Shift + D 复制物体，保留原点位置
Alt + D 关联复制，保留原点位置
Ctrl + J 合并对象，原点取活动对象原点

小键盘 . 聚焦选中对象
数字小键盘 1 / 3 / 7 切换前视图、右视图、顶视图，辅助精确定位

七、结语

物体原点是 Blender 局部坐标系统的核心。它既决定物体变换的默认参照，也影响修改器、约束、动画、父子关系、几何节点与纹理坐标的空间行为。原点并非几何中心，也不等同于世界原点或 3D 游标。掌握原点设置方法，尤其是 Shift + S 吸附菜单、Ctrl + 句号键（.） 仅影响原点模式、Ctrl + A 应用变换以及旧版 Ctrl + Shift + Alt + C 设置原点菜单，可显著提升建模、装配与动画工作流的可控性。在实际项目中，原点位置的合理性往往比几何体本身的精度更直接影响后续编辑效率。
